## Regras Importantes Para Humanos Curiosos

- Menos é mais, literalmente, as IA´s, apesar do raciocíno rápido, são bem limitadas quanto ao fluxo de informações.
- Se pedir para que o Codex ou Gemini faça muita coisa de uma só vez ele irá se confundir.
- Crie os mapas de antemão e apenas indique o caminho para ele.
- Por mais que já esteja nas regras, na primeira vez que gerar ele irá gerar com o templete de fala normal do RPGmaker, você precisará pedir para ele olhar o mapa 5 e trocar para os bustos novamente.
- Você deve dizer quando usar fade in e fade out.
- Se misturar liguagem inglesa com portuguesa no documento técnico, ele irá misturas as duas linguagens na hora de colocar os diálogos também.
- Ele tem dificuldade com acentuações e nada que eu fizesse resolveu isso, mas no âmbito geral, isso é coisa boba, já que todas as falas vão ser revisadas.
- Quebre a Cutscene no maior número de partes possíveis, de 1-3, o Codex entende melhor assim.
