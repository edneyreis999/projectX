# Plugins – Índice e Reuso

Este diretório reúne guias e documentação de plugins em uso no projeto. Antes de criar um novo plugin de quest, verifique aqui o que pode ser reaproveitado (padrões, comandos, mapeamentos de IDs, convenções de logs, etc.).

- Plano de padronização: `frontend/js/PLANO_PADRONIZACAO_PLUGINS.md`
- Template de documento: `frontend/docs/plugins/plugin-template.md`

## Como usar o template

- Copie `plugin-template.md` para um novo arquivo neste diretório, por exemplo: `frontend/docs/plugins/Coreto_Quest_<Nome>.md`.
- Preencha as seções com foco nas decisões específicas do seu plugin e referencie o NSD da quest correspondente em `frontend/docs/Quests`.
