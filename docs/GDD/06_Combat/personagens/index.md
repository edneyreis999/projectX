## Composição do Party

### Party Típica
1. **Filena** - Melee mobile, dashes para fechar distância
2. **Kilin** - Tank, protege party e aplica buffs de DEF
3. **Mhordred** - DPS frontal, dano bruto consistente
4. **Balastrus** - Suporte, debuffs e dano em área
5. **Thorin** - Ranged, precisão e setup

### Formação Típica

```
Frontline:    Kilin (Tank) -- Mhordred (DPS)
Midline:      Filena (Mobile)
Backline:     Balastrus (Suporte) -- Thorin (Ranged)
```

## Recursos de Combate

- **BP (Brave Points):** Todos usam sistema BTB para ações extra
- **Brave:** Habilidades poderosas custam BP positivo
- **Default:** Habilidades básicas podem gerar BP negativo
- **Ultimate:** Todas as classes possuem habilidade ultimate (+3 BP)
