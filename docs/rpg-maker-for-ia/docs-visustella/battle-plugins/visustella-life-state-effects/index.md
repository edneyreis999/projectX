# VisuStella MZ - Life State Effects

Documentação completa do plugin **Life State Effects** para RPG Maker MZ, desenvolvido pela VisuStella.

## Sobre Este Plugin

O plugin **Life State Effects** permite que traits e/ou states criem efeitos específicos comumente encontrados em JRPGs tradicionais, como Auto Life, Doom e Guts. Esses efeitos mecânicos adicionam uma nova camada de estratégia aos efeitos de status.

## Requisitos

- **RPG Maker MZ** (não compatível com outras versões)
- **VisuMZ_1_BattleCore** (obrigatório)
- **VisuMZ_1_SkillsStatesCore** (obrigatório)
- **Tier**: 3 (coloque abaixo de plugins de tier inferior)

## Características Principais

- **Auto Life**: Efeito que recupera uma porcentagem do HP ao morrer
- **Curse**: Impede recuperação de HP, MP e/ou TP
- **Doom**: Mata o battler quando o estado expira
- **Fragile**: Morte instantânea ao receber dano direto
- **Guts**: Previne que o HP caia abaixo de 1
- **Undead**: Inverte cura em dano e morte em cura
- **Death Transformations**: Inimigos se transformam ao morrer
