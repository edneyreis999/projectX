# Visao Geral - Action Sequence Camera Core

## Introducao

O plugin **Action Sequence Camera Core** adiciona novas funcoes de Action Sequence ao VisuStella Battle Core para dar controle total sobre a camera e zoom em batalha.

## Features

- Anexar camera a um ponto especifico na tela
- Anexar camera a alvo(s) especifico(s) na tela
- Pan da camera usando funcoes de offset
- Remover clamping para deixar a camera sair dos limites
- Definir nivel de zoom conforme desejado
- Inclinar (tilt) a camera ajustando o angulo
- Skew (distorcao) da camera em X e Y
- Nova opcao no menu para o jogador ligar/desligar camera em batalha

## Requisitos

| Requisito | Detalhe |
|-----------|---------|
| Engine | RPG Maker MZ |
| Plugin | Core Engine VisuStella MZ |
| Plugin | Battle Core VisuStella MZ |
| Tier | 3 (coloque abaixo de plugins de tier menor) |

## Acesso aos Comandos

Todos os Action Sequences deste plugin sao acessados **atraves do Battle Core**, nao diretamente por este plugin. Mantenha o Battle Core atualizado para ter acesso a todos os comandos.
