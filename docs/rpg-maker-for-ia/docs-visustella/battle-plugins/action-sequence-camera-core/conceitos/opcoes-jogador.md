# Opcoes do Jogador

## Controle de Camera pelo Jogador

O jogador tem a opcao de desligar os efeitos de camera em batalha. Se escolher desligar, **todos os efeitos deste plugin sao desabilitados** ate que ligue novamente.

## Motivacao: Motion Sickness

A opcao existe para dar ao jogador controle sobre como o jogo aparece visualmente, especialmente para jogadores que sofrem de motion sickness (enjoo de movimento) causado por movimentos de camera.

## Configuracao

Os parametros do plugin controlam como essa opcao aparece no menu:

| Parametro | Descricao |
|-----------|-----------|
| Add Option? | Adiciona a opcao Battle Camera ao menu |
| Adjust Window Height | Ajusta automaticamente a altura da janela |
| Options Name | Nome do comando no menu |

Detalhes completos em [parametros/options-menu.md](../parametros/options-menu.md).
