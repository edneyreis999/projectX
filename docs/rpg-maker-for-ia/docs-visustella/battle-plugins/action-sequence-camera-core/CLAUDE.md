# Action Sequence Camera Core - VisuStella MZ

Plugin Tier 3 de Action Sequences para controle de camera e zoom em batalha.

## Proposito

Adiciona funcoes de camera (pan, zoom, tilt, skew, clamp) como Action Sequences do Battle Core, permitindo controle cinematografico da camera durante sequencias de acao em batalha.

## Principais Areas

- **Action Sequences**: Comandos ANGLE, CAMERA, SKEW, ZOOM acessiveis via Battle Core
- **Concepts**: Spriteset rewrite, reset behavior, opcoes do jogador
- **Parameters**: Configuracao do menu de opcoes para o jogador
