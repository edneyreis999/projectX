# Auto Skill Trigger - VisuStella MZ

## Visão Geral
Sistema de triggers automáticos para skills que reagem a condições específicas em combate, como morte, dano elemental ou ações de aliados. Oferece 60 tipos diferentes de triggers para criar habilidades reativas e comportamentos tácticos.
