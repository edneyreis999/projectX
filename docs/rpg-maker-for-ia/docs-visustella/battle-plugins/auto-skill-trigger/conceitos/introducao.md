# Introdução ao Auto Skill Trigger

## Visão Geral

O Auto Skill Trigger é um sistema que permite criar skills que ocorrem automaticamente após condições específicas serem triggeradas. Isso inclui situações como morte, receber dano elemental específico, ou aliados realizando skills de determinado tipo.

[Nota: Este sistema permite criar comportamentos reativos e tácticos sem intervenção direta do jogador]

## Features Principais

O sistema inclui todas as seguintes funcionalidades (e mais):

### 1. Battle Triggers
- **Skill triggers que iniciam no começo da batalha**: Skills automáticas que ativam assim que o combate começa
- **Skill triggers que ativam ao vencer a batalha**: Comemorações ou efeitos finais quando a vitória é alcançada

### 2. Death Mechanics
- **Último ataque antes da morte**: Skills que permitem actors/enemies fazerem uma última ação antes de morrer
[Nota: Se a skill recuperar HP suficiente, o usuário não morre, mas outros efeitos de death ainda ocorrem]

### 3. User Action Reactions
Skills que funcionam como reação ao próprio usuário realizar ações específicas:
- Basic attacks (ataques básicos)
- Guarding (defesa)
- Items (uso de itens)
- Physical attacks (ataques físicos)
- Magical attacks (ataques mágicos)
- Certain hit attacks (ataques certeiros)
- Skills de tipos específicos
- Ações que inflictam dano elemental específico

### 4. Variedade de Triggers
- **Total de 60 diferentes auto triggers**: Cobrindo uma ampla variedade de situações e cenários táticos

## Casos de Uso Comuns

1. **Contra-ataques**: Skills que ativam quando o personagem é atacado
2. **Combo reactions**: Respostas automática a actions de aliados
3. **Elemental revenge**: Retaliação quando atingido por elementos específicos
4. **Passive buffs**: Efeitos que ativam automaticamente em condições específicas
5. **Death mechanics**: Última ação ou transformação antes da morte
