# Action Sequence Impact (VisuStella MZ)

Plugin Tier 3 que adiciona efeitos visuais de impacto em batalha usando Pixi JS Filters. Fornece Action Sequences para o Battle Core e efeitos automáticos em eventos de combate (críticos, dodges, guard).

## Propósito da Documentação

Catalogar e organizar a documentação do plugin Action Sequence Impact para consulta rápida por LLMs durante implementação de skills e Action Sequences.

## Principais Áreas

- **Efeitos Visuais**: 11 efeitos (Bizarro Inversion, Color Break, Desaturation, Motion Blur, Negative Inversion, Oversaturation, Shockwave, Motion Trail, Time Scale, Time Stop, Zoom Blur)
- **Action Sequences Impact**: Comandos IMPACT acessíveis via Battle Core
- **Action Sequences Inject**: Injeção de spritesheet animations em battlers
- **Parâmetros**: Configuração de efeitos automáticos (Critical Color Break, Dodge Motion Blur, Guard Shockwave)
