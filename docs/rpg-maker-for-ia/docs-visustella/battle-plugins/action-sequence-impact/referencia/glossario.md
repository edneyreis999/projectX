# Glossário - Action Sequence Impact

| Termo | Definição |
|-------|-----------|
| **Action Sequence** | Sequência de comandos executados durante ações de batalha no Battle Core |
| **Battlefield** | Área da tela onde ocorre o combate. Inclui sprites de battlers. UI e pictures podem ou não estar incluídos |
| **Chromatic Aberration** | Efeito visual onde cores RGB se separam em direções diferentes (Color Break) |
| **Color Break** | Efeito de separação cromática que ocorre em críticos ou via Action Sequence |
| **Easing Type** | Curva de animação que controla como o efeito transiciona (linear, ease-in, ease-out, etc.) |
| **IMPACT** | Prefixo dos comandos de Action Sequence para efeitos visuais deste plugin |
| **INJECT** | Prefixo dos comandos de Action Sequence para injeção de spritesheet animations |
| **Intensity Rate** | Valor entre 0 e 1 que controla a força de efeitos como Motion Blur |
| **Motion Blur** | Efeito de desfoque de movimento que simula rastro visual rápido |
| **Motion Trail** | Efeito que deixa cópias residuais do sprite ao longo da trajetória de movimento |
| **Pixi JS Filters** | Biblioteca de filtros WebGL usada por este plugin para efeitos visuais |
| **Shockwave** | Ondas de choque que se propagam radialmente a partir de um ponto |
| **Spritesheet Animation** | Animação baseada em grid de frames em um arquivo de imagem |
| **Time Scale** | Velocidade do tempo na batalha. 1.00 = normal, menor = lento, maior = rápido |
| **Tier** | Nível de prioridade no Plugin Manager. Plugins de tier menor devem ficar acima |
| **Zoom Blur** | Efeito de desfoque radial direcionado a um ponto focal específico |
