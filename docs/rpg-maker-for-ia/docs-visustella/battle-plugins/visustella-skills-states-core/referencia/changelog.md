# Changelog

Histórico de versões do Skills & States Core.

---

## Version 1.48: December 19, 2024
* **New Features**
  - Auras & Miasmas (Olivia): passive states que afetam party aliado (Aura) ou oponente (Miasma)
  - Notetags: `<Aura State>`, `<Miasma State>`, `<Not User Aura>`, `<Allow Dead Aura/Miasma>`, `<Dead Aura/Miasma Only>`
* **Optimization**: Plugin mais otimizado

## Version 1.47: August 29, 2024
* **New Features** (Arisu)
  - `<Bypass State Damage Removal>` notetags: Attacker, Target, Skill/Item variants

## Version 1.46: July 18, 2024
* **New Features** (Irina)
  - Plugin Parameter: Sort Alphabetical para Skill Types
  - Notetag: `<ID Sort Priority: x>`

## Version 1.45: May 16, 2024
* **Bug Fix**: Passive state conditional notetags (Irina)

## Version 1.44: April 18, 2024
* **Bug Fixes**: Passive states não aparecendo, crash ao limpar cache (Olivia)
* **Optimization**: States com muito texto em notes não causam FPS drops

## Version 1.43: January 18, 2024
* **New Features** (Arisu): Plugin Commands para Skill Cost Emulate e State Turns Change

## Version 1.42: November 16, 2023
* **Bug Fix**: variável `origin` em `<JS On Expire State>` (Irina)

## Version 1.41: September 14, 2023
* **Bug Fix**: `<Max Turns: x>` para states não funcionava (Arisu)
* **Compatibility**: funcionalidades para plugins futuros

## Version 1.40: August 17, 2023
* **Bug Fix**: Item Cost consumindo key items e non-consumable

## Version 1.39: July 13, 2023
* **Feature Update**: Item Cost não consome key items/non-consumable

## Version 1.38: March 16, 2023
* **New Features** (Arisu/FAQ): Item/Weapon/Armor Cost notetags

## Version 1.37: January 20, 2023
* **Bug Fix**: Equipment unequip com passive states (Irina)

## Version 1.36: December 15, 2022
* **Feature Update**: Group Defeat dá EXP/Gold/Drops
* **New**: Skill Type Window Width parameter (Irina)

## Version 1.35: October 13, 2022
* **Feature Update**: Switch/Variable Refresh defaults para false

## Version 1.34: September 29, 2022
* **New**: Gauge Settings parameters (Irina/AndyL)

## Version 1.33: August 11, 2022
* **Bug Fix**: Custom action sequence sem skill (Olivia)

## Version 1.32: June 16, 2022
* **New**: Switch Refresh? e Variable Refresh? parameters (Arisu)

## Version 1.31 - 1.00: 2022-2020
* Múltiplos bug fixes, feature updates e otimizações
* Principais adições: Slip Refresh, Turn End on Map, Slip Damage fixes, Passive State explanations, JS notetags
