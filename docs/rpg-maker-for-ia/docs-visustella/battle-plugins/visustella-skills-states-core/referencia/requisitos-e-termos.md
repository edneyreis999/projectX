# Requisitos e Termos de Uso

---

## Requisitos

- **Engine**: RPG Maker MZ (não funciona em outras versões)
- **Tier**: 1 (coloque ABAIXO de plugins de tier menor na Plugin Manager list: 0, 1, 2, 3, 4, 5)

### Plugins Opcionais Compatíveis
| Plugin | Funcionalidade Extra |
|--------|---------------------|
| VisuMZ_1_MessageCore | Cores hex `#rrggbb` em Turn Color |
| VisuMZ_1_BattleCore | Action Sequences, JS Pre/Post-Regenerate |
| VisuMZ_0_CoreEngine | Layout de windows (sobrescrito pelo Updated Layout) |
| VisuMZ_2_ClassChangeSystem | Passive Condition Multiclass |
| Items & Equips Core | Shop Status Window no Skill Menu |
