# Plugin Parameters - General Skill Settings

Configurações gerais relacionadas ao Skill Menu Scene e skill types.

---

## General

| Parâmetro | Descrição |
|-----------|-----------|
| **Use Updated Layout** | Usa o layout atualizado do Skill Menu fornecido pelo plugin. Habilita automaticamente o Status Window. Sobrepõe Core Engine window settings. |
| **Layout Style** | Estilo do menu: Upper/Lower Help + Left/Right Input (4 combinações) |

---

## Skill Type Window

| Parâmetro | Descrição | Default |
|-----------|-----------|---------|
| **Style** | Como desenhar comandos: Text Only, Icon Only, Icon + Text, Auto | - |
| **Text Align** | Alinhamento de texto | - |
| **Window Width** | Largura em pixels | 240 |

---

## List Window

| Parâmetro | Descrição |
|-----------|-----------|
| **Columns** | Número máximo de colunas |

---

## Shop Status Window

| Parâmetro | Descrição |
|-----------|-----------|
| **Show in Skill Menu?** | Mostrar Shop Status Window no Skill Menu. Habilitado automaticamente com Updated Layout. |
| **Adjust List Window?** | Ajustar automaticamente o Skill List Window ao usar Shop Status Window |
| **Background Type** | 0-Window, 1-Dim, 2-Transparent |
| **JS: X, Y, W, H** | Código para dimensões do Shop Status Window |

---

## Skill Types

| Parâmetro | Descrição |
|-----------|-----------|
| **Hidden Skill Types** | IDs de Skill Types ocultos no jogo |
| **Hidden During Battle** | IDs ocultos apenas durante batalha |
| **Icon: Normal Type** | Ícone para skill types sem ícone atribuído |
| **Icon: Magic Type** | Ícone para magic skill types sem ícone atribuído |
| **Sort: Alphabetical** | IDs de Skill Types ordenados alfabeticamente |

**Dica**: Atribua ícones a skill types inserindo `\I[x]` no nome do skill type no Database > Types.

---

## Global JS Effects

| Parâmetro | Descrição |
|-----------|-----------|
| **JS: Skill Conditions** | Código JavaScript para condição global de skills |
