# Plugin Parameters - Gauge Settings

Configurações visuais dos gauges de Skill Cost Types exibidos no battle scene e menus.

---

## Labels

| Parâmetro | Descrição |
|-----------|-----------|
| **Font Type** | Tipo de fonte para labels |
| **Match Label Color** | Cor do label igual à cor do gauge |
| **Match: Gauge #?** | Qual Gauge Color corresponder |
| **Preset: Gauge Color** | Número (Window Skin) ou `#rrggbb` |
| **Solid Outline** | Outline preto sólido |
| **Outline Width** | Largura do outline (0 = sem outline) |

---

## Values

| Parâmetro | Descrição |
|-----------|-----------|
| **Font Type** | Tipo de fonte para valores |
| **Solid Outline** | Outline preto sólido |
| **Outline Width** | Largura do outline (0 = sem outline) |
