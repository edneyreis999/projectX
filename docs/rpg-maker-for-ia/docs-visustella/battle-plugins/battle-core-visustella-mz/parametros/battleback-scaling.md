# Battleback Scaling Settings - Plugin Parameters

## Visão Geral

Controla como os battlebacks (fundos de batalha) são escalados no jogo. Por padrão, o RPG Maker MZ escala battlebacks como se a tela fosse 816x624, o que nem sempre é o caso. Estas configurações NÃO podem ser alteradas durante o jogo ou por batalha.

## Parâmetros

### Settings

#### Default Style
- **Descrição**: Estilo de escalamento padrão para battlebacks
- **Notas**:
  - **MZ**: Estilo padrão do MZ
  - **1:1**: Sem escalamento
  - **Scale To Fit**: Escala para tamanho da tela
  - **Scale Down**: Reduz se maior que a tela
  - **Scale Up**: Amplia se menor que a tela

#### JS: 1:1
- **Descrição**: Código para controle de escalamento do estilo 1:1
- **Notas**: Permite customização via JavaScript

#### JS: Scale To Fit
- **Descrição**: Código para controle de escalamento do estilo Scale To Fit
- **Notas**: Permite customização via JavaScript

#### JS: Scale Down
- **Descrição**: Código para controle de escalamento do estilo Scale Down
- **Notas**: Permite customização via JavaScript

#### JS: Scale Up
- **Descrição**: Código para controle de escalamento do estilo Scale Up
- **Notas**: Permite customização via JavaScript
