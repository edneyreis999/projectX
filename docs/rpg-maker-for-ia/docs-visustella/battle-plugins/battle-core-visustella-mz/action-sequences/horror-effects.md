# Horror Effects - Action Sequence

## Visão Geral
Action Sequences relacionadas a Horror Effects.
**Requer VisuMZ_2_HorrorEffects!**

## Comandos Disponíveis

### HORROR: Clear All Filters
Limpa todos os filtros de Horror Effects do battler alvo.

**Parâmetros:**
- **Targets**: Unidade(s) para remover efeitos

**Exemplo:**
```
HORROR: Clear All Filters
  Targets: Target
```

### HORROR: Glitch Create
Cria efeito de glitch no battler alvo.

**Parâmetros:**
- **Targets**: Unidade(s) para criar efeito
- **Glitch Slices**: Fatias de glitch para usar
- **Glitch Offset**: Valor de offset padrão
- **Glitch Animated?**: Animar o glitch?
- **Glitch Frequency**: Frequência do glitch (menor=mais frequente)
- **Glitch Strength**: Força do glitch (maior=mais forte)

### HORROR: Glitch Remove
Remove efeito de glitch do battler alvo.

**Parâmetros:**
- **Targets**: Unidade(s) para remover efeito

### HORROR: Noise Create
Cria efeito de noise no battler alvo.

**Parâmetros:**
- **Targets**: Unidade(s) para criar efeito
- **Noise Rate**: Taxa de noise
- **Noise Animated**: Animar o noise?

### HORROR: Noise Remove
Remove efeito de noise do battler alvo.

**Parâmetros:**
- **Targets**: Unidade(s) para remover efeito

### HORROR: TV Create
Cria efeito de TV no battler alvo.

**Parâmetros:**
- **Targets**: Unidade(s) para criar efeito
- **TV Line Thickness**: Espessura das linhas (menor=mais fino)
- **TV Corner Size**: Tamanho dos cantos (menor=menor)
- **TV Animated**: Animar a TV?
- **TV Speed**: Velocidade da animação (menor=mais lento)

### HORROR: TV Remove
Remove efeito de TV do battler alvo.

**Parâmetros:**
- **Targets**: Unidade(s) para remover efeito

## Notas
- Horror Effects adicionam atmosfera de terror/horror
- Glitch cria distorção visual de artefatos digitais
- Noise adiciona granulação estática
- TV simula efeito de monitor antigo/ruído
- Efeitos podem ser animados para maior impacto
- Ideal para jogos de horror ou habilidades sobrenaturais
