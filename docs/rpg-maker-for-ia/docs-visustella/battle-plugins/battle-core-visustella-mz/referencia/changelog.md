## Notas sobre Atualizações

### Sempre Atualize
Mantenha o plugin atualizado para:
- Bug fixes
- New features
- Performance improvements
- Security fixes

### Compatibilidade
- Sempre verifique changelogs de plugins relacionados
- Atualize todos os plugins VisuStella MZ juntos quando possível
- Backup seu projeto antes de atualizar

### Breaking Changes
Mudanças breaking são raramente introduzidas, mas quando ocorrem:
- Serão claramente marcadas no changelog
- Documentação será atualizada
- Migração guides serão fornecidos quando necessário
