# Termos de Uso - Battle Core

## Visão Geral

Estes são os termos de uso oficiais para o plugin **VisuStella MZ Battle Core**.

## 1. Uso Permitido

Estes plugins podem ser usados em jogos:
- ✅ **Gratuitos**
- ✅ **Comerciais**

**Condição**: Devem ser adquiridos através de meios legítimos em:
- VisuStella.com
- Outras fontes oficiais aprovadas VisuStella

**Exceções**: Circunstâncias especiais que proíbem uso serão listadas em VisuStella.com.

## 2. Créditos Obrigatórios

**Todos os coders listados** na seção Credits deste plugin **devem ser creditados** em seus jogos.

### Opções de Crédito

Você pode creditar de duas formas:

#### Opção 1: Credit Individual
Listar cada membro individualmente:
- Yanfly
- Arisu
- Olivia
- Irina

#### Opção 2: Credit Coletivo
Creditar como coletivo sob o nome:
```
"VisuStella"
```

## 3. Edição do Código

✅ **PERMITIDO**: Editar o source code para suit suas necessidades

**Condições**:
- ❌ **NÃO** pode claim que o source code pertence a você

### Responsabilidade sobre Código Modificado

VisuStella **NÃO** se responsabiliza pelo plugin se:
- Quaisquer mudanças foram feitas no código do plugin
- User-provided custom code foi usado para custom control effects

Isso inclui:
- Advanced JavaScript notetags
- Plugin parameters que permitem custom JavaScript code

## 4. Redistribuição Proibida

❌ **NÃO** pode:
- Redistribuir estes plugins
- Pegar código deste plugin para usar como seu próprio

**Locais Permitidos**:
Plugins devem ser baixados apenas de:
- VisuStella.com
- Outras fontes oficiais/aprovadas VisuStella

Uma lista de fontes oficiais/aprovadas pode ser encontrada em VisuStella.com.

## 5. Limitação de Responsabilidade

VisuStella **NÃO** é responsável por:

### Problemas em Seu Jogo
- Uso não intencional do plugin
- Problemas de incompatibilidade com plugins **fora** da biblioteca VisuStella MZ
- Versões de plugin não atualizadas

### Compatibility Patches de Terceiros
- Funcionamento adequado de compatibility patches feitos por terceiros

### Erros de Código Customizado
- Erros causados por user-provided custom code
- Used para custom control effects

Isso inclui:
- Advanced JavaScript notetags
- Plugin parameters que permitem JavaScript code

## 6. Compatibility Patches de Terceiros

Se uma compatibility patch precisa ser feita através de um terceiro:
- **NÃO afiliado** com VisuStella
- **Envolvendo** código da biblioteca VisuStella MZ

### Requisitos

1. **Contato** deve ser feito com um membro da VisuStella
2. **Aprovação** deve ser obtida
3. **Local** da patch:
   - Colocada em VisuStella.com
   - Como download gratuito para o público

### Proibições

Estas patches **NÃO** podem ser:
- Vendidas para ganho monetário
- Incluindo:
  - Commissions
  - Crowdfunding
  - Donations
