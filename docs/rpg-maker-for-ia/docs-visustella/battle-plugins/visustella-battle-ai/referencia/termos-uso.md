### Código Customizado

Inclui, mas não se limita a:
- JavaScript notetags avançados
- Plugin parameters que permitem código JavaScript
- Qualquer outro código customizado inserido pelo usuário

## Artigo 6: Compatibility Patches

Se um compatibility patch precisar ser feito através de um terceiro que **não é afiliado** à VisuStella e envolve usar código da biblioteca VisuStella MZ:

1. **Contato deve ser feito** com um membro da VisuStella
2. **Aprovação é necessária** antes do patch ser usado
3. **Patch será colocado** em VisuStella.com como download gratuito ao público
4. **Venda proibida**: Tais patches não podem ser vendidos por ganho monetário, incluindo:
   - Comissões
   - Crowdfunding
   - Doações

## Artigo 7: Equipes de Projeto

Se este plugin VisuStella MZ é um **produto pago**, todos os membros da equipe do projeto devem comprar suas próprias cópias individuais do produto pago se forem usá-lo.

### Uso Inclui

- Trabalhar em mecânicas de jogo relacionadas
- Gerenciar código relacionado
- Usar Plugin Commands e funcionalidades relacionadas

### Redistribuição na Equipe

Redistribuição do plugin e/ou seu código para outros membros da equipe **NÃO é permitida** a menos que eles próprios possuam o plugin, pois isso conflita com o Artigo 4.

## Perguntas Frequentes

### Posso usar este plugin em jogos comerciais?

✅ **Sim**, desde que adquirido através de meios legítimos em VisuStella.com ou fontes oficiais aprovadas.

### Preciso creditar os autores individualmente?

❌ **Não**, você pode creditar como "VisuStella" coletivamente ou creditar individualmente os membros da equipe.

### Posso modificar o código?

✅ **Sim**, você pode modificar para atender suas necessidades, mas não pode reivindicar o código como seu.

### Posso redistribuir este plugin?

❌ **Não**, você não pode redistribuir este plugin ou seu código.

### Posso criar um compatibility patch?

✅ **Sim**, mas se o patch envolve código VisuStella MZ, você deve:
1. Entrar em contato com a VisuStella
2. Obter aprovação
3. O patch será distribuído gratuitamente em VisuStella.com

### Todos os membros da minha equipe precisam comprar?

✅ **Sim**, se for um plugin pago, cada membro da equipe que trabalhar com ele deve ter sua própria cópia.

### Onde posso baixar oficialmente?

Apenas de **VisuStella.com** ou fontes oficiais aprovadas listadas no site.
