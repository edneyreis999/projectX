# Glossario

| Termo | Definicao |
|-------|-----------|
| **Trait Set** | Propriedade atribuida em massa a battlers via notetags. 10 tipos disponiveis. |
| **Element** | Trait Set tipo primario. Define fraquezas/resistencias elementais. |
| **SubElement** | Trait Set tipo secundario. Sub-tipos elementais. |
| **Gender** | Trait Set para genero do battler. |
| **Race** | Trait Set para raca do battler. |
| **Nature** | Trait Set para natureza/personalidade. |
| **Alignment** | Trait Set para alinhamento moral. |
| **Blessing** | Trait Set para bencao positiva. |
| **Curse** | Trait Set para maldicao negativa. |
| **Zodiac** | Trait Set para signo zodiacal. |
| **Variant** | Trait Set para variante do inimigo (mais forte/fraco). |
| **Received** | Modificadores no dano recebido pelo target. |
| **Dealt** | Modificadores no dano causado pelo user. |
| **Plus** | Modificador aditivo aplicado antes da taxa multiplicativa. |
| **Rate** | Modificador multiplicativo aplicado ao resultado. |
| **Flat** | Modificador aditivo aplicado apos a taxa multiplicativa. |
| **Multi-Element** | Acao com multiplos elementos simultaneos. |
| **Element Absorb** | Habilidade de absorver dano elemental (converte em cura). |
| **Element Reflect** | Habilidade de refletir dano elemental (retorna ao atacante). |
| **Element Pierce** | Habilidade de ignorar imunidade, reflexao e absorcao. |
| **Force Action Element** | Forca a acao a usar elemento especifico. |
| **Force Received Element Rate** | Forca o target a receber dano a taxa especifica. |
| **Status Menu Layout** | Layout atualizado do menu de status do plugin. |
| **Category Window** | Janela de categorias no Status Menu atualizado. |
| **Random Weight** | Peso de probabilidade para randomizacao de Trait Sets. |
| **Format Text** | Texto adicionado ao nome do inimigo pelo Trait Set. |
| **Trait Column** | Coluna de exibicao de traits no Status Menu. |
| **Tier 1** | Nivel de prioridade do plugin no Plugin Manager (0-5). |
