# Notetag - Biografia do Ator

## Biography

Define a biografia do ator exibida no Status Menu atualizado.

```
<Biography>
 text
 text
 text
</Biography>
```

- **Usado em**: Actor
- Text codes sao permitidos
- Pode ser alterada mid-game via Plugin Command
- Se nao usada, exibe o profile message do ator como biografia
