# Parametros - Categorias do Status Menu

Permite adicionar categorias customizadas ao Status Menu. So se aplica se o Updated Status Menu Layout estiver habilitado.

## Category

Cada categoria customizada possui:

| Parametro | Descricao |
|-----------|-----------|
| **Symbol** | Simbolo usado para esta categoria |
| **Icon** | Icone usado (0 para nenhum) |
| **Text** | Nome de texto da categoria |
| **JS: Draw Data** | Codigo JavaScript para determinar o que aparece na data window |

## Nota

O JS: Draw Data permite total controle sobre o conteudo exibido, incluindo acesso a dados do ator, parametros, trait sets, etc.
