# VisuStella Elements & Status Menu Core

**Plugin**: The Elements & Status Menu Core
**Autor**: VisuStella MZ
**Tier**: 1 (colocar acima de plugins tier 0)
**Requisito**: RPG Maker MZ

## Propósito

Controle avançado de cálculos de dano elemental, Trait Sets para atribuição em massa de traits, e atualização do Status Menu para exibir todas as informações.

## Extensões

- Anti-Damage Barriers VisuStella MZ
- Weakness Display VisuStella MZ
