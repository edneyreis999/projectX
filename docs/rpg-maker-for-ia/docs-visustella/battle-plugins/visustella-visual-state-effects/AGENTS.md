# Visual State Effects — VisuStella MZ

Plugin de efeitos visuais para states, buffs e debuffs no RPG Maker MZ.

## Propósito

Amplia a capacidade do engine de exibir informações visuais sobre states/buffs/debuffs: popups customizados, animações, overlays, tone, opacity, hover e breathing.

## Principais Áreas

- **Notetags de State**: Popup, animações (add/erase/repeat), overlay customizado, motion, motion lock, tone, opacity, rainbow → [notetags/states.md](notetags/states.md)
- **Notetags de Hover/Breathing**: Efeitos visuais de flutuação e respiração → [notetags/hover.md](notetags/hover.md), [notetags/breathing.md](notetags/breathing.md)
- **Referência Rápida**: Cheat sheet de todas notetags → [notetags/referencia-rapida.md](notetags/referencia-rapida.md)
- **Parâmetros**: Configuração de popups, animações, overlays → [parametros/](parametros/)
- **Performance**: Warnings sobre repeat animations e breathing → [referencia/performance.md](referencia/performance.md)
