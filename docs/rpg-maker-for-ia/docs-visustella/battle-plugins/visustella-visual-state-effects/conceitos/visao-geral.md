# Visão Geral — Visual State Effects (VisuStella MZ)

## Identificação

- **Nome**: Visual State Effects VisuStella MZ
- **Tier**: 3 (deve ser colocado abaixo de plugins de tier inferior)
- **Tipo**: Mechanic — efeitos visuais para states, buffs e debuffs
- **Requisitos**: RPG Maker MZ (não funciona em outras versões)

## Dependências Obrigatórias

Plugins que devem estar instalados e posicionados **acima** deste no Plugin Manager:

1. Core Engine VisuStella MZ
2. Battle Core VisuStella MZ
3. Skills and States Core VisuStella MZ

## Propósito

States, buffs e debuffs são aspectos críticos do sistema de batalha. Este plugin amplia a capacidade do RPG Maker MZ de transmitir informações visuais sobre esses efeitos ao jogador, superando as limitações do engine padrão.

## Funcionalidades

- Exibir State Overlays e State Icons sobre actors e enemies
- Criar text popups para Buffs, Debuffs e States com controle total de cor, flash e duração
- Reproduzir animações ao receber ou remover Buffs, Debuffs e States
- States podem ter animações repetitivas (repeating animations)
- States podem alterar o tom (tone) de um sprite
- States podem congelar um sprite no lugar (motion lock)
- Efeitos de hover aplicáveis visualmente a trait objects
- Efeitos de breathing experimentais com distorção de sprite
