# Parâmetros — State Settings

## Popups

| Parâmetro | Descrição |
|-----------|-----------|
| Show Popups? | Exibir popups ao aplicar/remover states |
| Allow Duplicates? | Permitir popups duplicados no mesmo frame |
| Battle End Popups? | Exibir popup de remoção ao fim da batalha |

### Formatos

| Parâmetro | Descrição |
|-----------|-----------|
| Add State Format | Texto ao aplicar state. `%1` = State Name |
| Erase State Format | Texto ao remover state. `%1` = State Name |

### Defaults

| Propriedade | Descrição |
|-------------|-----------|
| Default Text Color | `#rrggbb` ou número do Window Skin |
| Match Turn Count? | Cor do turno igual à cor padrão |
| Flash Color | `[red, green, blue, alpha]` |
| Flash Duration | Frames de duração do flash |

## State Animations

### Add/Erase Animations

| Parâmetro | Descrição |
|-----------|-----------|
| Mirror Animations? | Espelhar animações de state |
| Mute Animations? | Silenciar animações de state |

### Repeating Animations

| Parâmetro | Descrição |
|-----------|-----------|
| Cycle Time | Frames de espera entre ciclos. **WARNING**: valores baixos = risco de lag |
| Mirror Animations? | Espelhar repeating animations por padrão |
| Mute Animations? | Silenciar repeating animations por padrão |
