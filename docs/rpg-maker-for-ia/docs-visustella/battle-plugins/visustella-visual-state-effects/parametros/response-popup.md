# Parâmetros — Response Popup Settings

Configurações de popup para efeitos de resposta: contra-ataque (counterattack), reflexão mágica (magic reflection) e substituição (substitute).

## Tipos de Response Popup

| Tipo | Descrição |
|------|-----------|
| Counter Popup | Popup de contra-ataque |
| Reflect Popup | Popup de reflexão mágica |
| Substitute Popup | Popup de substituição |

## Propriedades (comum a todos)

| Propriedade | Descrição |
|-------------|-----------|
| Text | Texto exibido ao ativar o efeito |
| Icon Index | Ícone usado no popup |
| Text Color | `#rrggbb` ou número do Window Skin |
| Flash Color | `[red, green, blue, alpha]` (0–255) |
| Flash Duration | Frames de duração do flash |
