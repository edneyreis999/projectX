# Parâmetros — Buff/Debuff Settings

## Popups

| Parâmetro | Descrição |
|-----------|-----------|
| Show Popups? | Exibir popups de Buff/Debuff ao aplicar |
| Buff Format | Formato do texto de buff. `%1` = Parameter Name |
| Debuff Format | Formato do texto de debuff. `%1` = Parameter Name |

### Formato de cada popup (Buff e Debuff)

| Propriedade | Descrição |
|-------------|-----------|
| Text Color | `#rrggbb` ou número do Window Skin |
| Flash Color | `[red, green, blue, alpha]` (0–255) |
| Flash Duration | Frames de duração do flash |

## Animações

| Parâmetro | Descrição |
|-----------|-----------|
| Show Animations? | Exibir animações de Buff/Debuff ao aplicar |
| Mirror Animations? | Espelhar animações |
| Mute Animations? | Silenciar animações |

## Buff/Debuff Animations por Parâmetro

Cada parâmetro de battler tem uma animação configurável para Buff e Debuff:

| Parâmetro | Buff Animation | Debuff Animation |
|-----------|---------------|------------------|
| MaxHP | Configurável | Configurável |
| MaxMP | Configurável | Configurável |
| ATK | Configurável | Configurável |
| DEF | Configurável | Configurável |
| MAT | Configurável | Configurável |
| MDF | Configurável | Configurável |
| AGI | Configurável | Configurável |
| LUK | Configurável | Configurável |
