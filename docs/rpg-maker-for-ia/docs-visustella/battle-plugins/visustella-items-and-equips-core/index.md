# Items & Equips Core VisuStella MZ

Plugin Tier 1 para RPG Maker MZ que melhora as cenas de Item, Equipamento e Shop, adicionando categorias customizáveis, controle avançado de parâmetros, rulings de equipamento, e muito mais.
