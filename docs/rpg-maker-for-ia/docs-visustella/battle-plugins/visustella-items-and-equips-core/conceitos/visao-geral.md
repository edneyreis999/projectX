# Visão Geral - Items & Equips Core

## Introdução

O Items & Equips Core melhora as cenas dedicadas a itens e equipamentos do RPG Maker MZ (incluindo o shop) e como são gerenciadas. Oferece mais categorias de itens, melhor controle de parâmetros, rulings de equipamento, e mais.

## Features Principais

- Modificação da aparência das cenas Item, Equip e Shop
- Categorização de itens em categorias únicas e múltiplas
- Item Scene e Shop Scene exibem informações detalhadas sobre itens
- Marcador "NEW!" sobre itens recentemente adquiridos
- Notetags de equipamento para ajustar parâmetros além dos limites do editor
- Equipment Rulings para ajustar quais slot types podem/não podem ser removidos ou otimizados
- Equipment Type Handling oferece mais controle sobre loadouts de equipamento
- Itens no shop podem ser ocultados/exibidos baseado em Switches
- Itens no shop podem ter preços variáveis ajustados por notetags

## Requisitos

- RPG Maker MZ (não funciona em outras versões)
- **Tier 1**: Colocar abaixo de plugins de tier menor no Plugin Manager (ordem: 0, 1, 2, 3, 4, 5)
