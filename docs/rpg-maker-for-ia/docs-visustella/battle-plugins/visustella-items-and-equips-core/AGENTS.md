# Items & Equips Core VisuStella MZ

Plugin Tier 1 de qualidade de vida para RPG Maker MZ que melhora as cenas de Item, Equipamento e Shop.

## Propósito

Permite controle avançado sobre itens, equipamentos e lojas: categorias customizáveis, parâmetros além dos limites do editor, requisitos de equipamento, itens amaldiçoados, preços dinâmicos, e visibilidade condicional no shop.

## Principais Áreas

- **conceitos/**: Visão geral, Equipment Type Handling, Shop Status Window
- **notetags/**: Notetags gerais, de acessibilidade, equipamento, status window, shop menu + referência rápida
- **parametros/**: Configuração de Item Menu, Categories, NEW Labels, Equip Menu, Shop Menu, Shop Status Window
- **comandos/**: Plugin Commands para Actor, Purify e Shop
- **referencia/**: Compatibilidade e plugins de extensão
