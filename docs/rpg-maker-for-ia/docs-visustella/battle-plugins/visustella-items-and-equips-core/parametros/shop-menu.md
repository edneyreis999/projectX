# Plugin Parameters: Shop Menu Settings

Configuração da cena de Shop Menu.

---

## General

| Parâmetro | Descrição |
|-----------|-----------|
| Use Updated Layout | Usa layout atualizado. Sobrepõe Core Engine settings |
| Layout Style | Upper/Lower Help + Left/Right Input |

---

## Switches

| Parâmetro | Descrição |
|-----------|-----------|
| Switch: Buy | Switch ligada ao comprar. Reverte a OFF ao abrir o Shop Scene |
| Switch: Sell | Switch ligada ao vender. Reverte a OFF ao abrir o Shop Scene |

---

## Command Window

| Parâmetro | Descrição |
|-----------|-----------|
| Hide Unavailable? | Oculta comandos indisponíveis (ex: shop Purchase Only) |
| Style | Text Only / Icon Only / Icon + Text / Auto |
| Text Align | Alinhamento do texto |
| Buy Icon | Ícone do comando Buy |
| Sell Icon | Ícone do comando Sell |
| Cancel Icon | Ícone do comando Cancel |
| Rename "Cancel" | Renomear Cancel para outro texto |

---

## Prices

| Parâmetro | Descrição |
|-----------|-----------|
| Sell Price Rate | Taxa padrão do preço de venda |
| JS: Buy Price | Modificações no preço de compra antes de finalizar |
| JS: Sell Price | Modificações no preço de venda antes de finalizar |

---

## Button Assist Window

| Parâmetro | Descrição |
|-----------|-----------|
| Small Increment | Texto para incrementar quantidade comprada/vendida |
| Large Increment | Texto para incrementar grande quantidade (requer Core Engine) |
