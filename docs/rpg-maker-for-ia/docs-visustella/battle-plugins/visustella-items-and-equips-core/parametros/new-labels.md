# Plugin Parameters: NEW! Labels

Marcador "NEW!" colocado sobre o ícone de itens recém-adicionados ao inventário.

---

| Parâmetro | Descrição |
|-----------|-----------|
| Use NEW! Labels? | Ativar/desativar o marcador |
| Icon | Índice do ícone para o marcador (0 = sem ícone) |
| Text | Texto exibido no marcador |
| Font Color | Cor do texto. `#rrggbb` ou número da Window Skin |
| Font Size | Tamanho da fonte |
| Fade Limit | Limite superior de opacidade antes de reverter |
| Fade Speed | Velocidade do fade |
| Offset X | Deslocamento horizontal |
| Offset Y | Deslocamento vertical |
