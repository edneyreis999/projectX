# Plugin Parameters: Equip Menu Settings

Configuração da cena de Equipment Menu.

---

## General

| Parâmetro | Descrição |
|-----------|-----------|
| Use Updated Layout | Usa layout atualizado. Sobrepõe Core Engine settings |
| Param Font Size | Tamanho da fonte para valores de parâmetros |
| Show Menu Portraits? | Se Main Menu Core instalado, exibe Menu Portraits ao invés de face |
| JS: Portrait Upper | Código para desenhar dados superiores com portrait |
| JS: Face Upper | Código para desenhar dados superiores com face |
| JS: Parameter Lower | Código para parâmetros na parte inferior do Status Window |
| Layout Style | Upper/Lower Help + Left/Right Input |
| Status Window Width | Largura do status window (sem Updated Layout) |
| Show Back Rectangles? | Retângulos escuros para melhor contraste |
| Cursed Equip Popup | Texto popup ao equipar item amaldiçoado. `%1`=Actor, `%2`=Equip, `%3`=Icon. Requer Core Engine |

---

## Command Window

| Parâmetro | Descrição |
|-----------|-----------|
| Style | Text Only / Icon Only / Icon + Text / Auto |
| Text Align | Alinhamento do texto |
| Equip Icon | Ícone do comando Equip |
| Add Optimize Command? | Adicionar comando Optimize |
| Optimize Icon | Ícone do comando Optimize |
| Add Clear Command? | Adicionar comando Clear |
| Clear Icon | Ícone do comando Clear |

---

## Remove Equip

| Parâmetro | Descrição |
|-----------|-----------|
| Icon | Ícone para remoção de equipamento |
| Text | Texto para remoção de equipamento |
| Use SHIFT Shortcut? | Usar SHIFT como atalho para remover |

---

## Rulings

| Parâmetro | Descrição |
|-----------|-----------|
| Equip-Adjust HP/MP | Ajustar diferenças de HP/MP após trocar equips com MaxHP/MaxMP |
| Non-Removable Types | IDs de Equipment Types que devem sempre ter um item equipado |
| Non-Optimized Types | IDs de Equipment Types ignorados na otimização |

---

## Button Assist Window

| Parâmetro | Descrição |
|-----------|-----------|
| SHIFT: Remove | Texto do botão assist para remoção via SHIFT (requer Core Engine) |
