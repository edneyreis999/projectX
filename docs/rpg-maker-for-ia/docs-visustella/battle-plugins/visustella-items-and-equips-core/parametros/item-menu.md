# Plugin Parameters: Item Menu Settings

Configuração da cena de Item Menu.

---

## General Window

| Parâmetro | Descrição |
|-----------|-----------|
| Use Updated Layout | Usa layout atualizado. Habilita Status Window automaticamente. Sobrepõe Core Engine settings |
| Disabled: Vanilla | Se NÃO usar updated layout, mantém tudo vanilla. Desabilita: categorias customizadas, Shop Status Window, Modern Controls, columns > 2 |
| Layout Style | Upper/Lower Help + Left/Right Input (4 combinações) |

---

## List Window

| Parâmetro | Descrição |
|-----------|-----------|
| Columns | Número máximo de colunas. Com Modern Controls do Core Engine, usar Page Up/Down para múltiplas colunas |

---

## Item Quantity

| Parâmetro | Descrição |
|-----------|-----------|
| Item Max | Quantidade máxima padrão para items |
| Weapon Max | Quantidade máxima padrão para weapons |
| Armor Max | Quantidade máxima padrão para armors |
| Quantity Format | Como exibir quantidade. `%1` = quantidade |
| Font Size | Tamanho da fonte da quantidade |

---

## Shop Status Window

| Parâmetro | Descrição |
|-----------|-----------|
| Show in Item Menu? | Exibe Shop Status Window no Item Menu |
| Adjust List Window? | Ajusta automaticamente Item List Window se usando Shop Status Window |
| Background Type | 0 - Window, 1 - Dim, 2 - Transparent |
| JS: X, Y, W, H | Código para dimensões do Status Window |

---

## Button Assist Window

| Parâmetro | Descrição |
|-----------|-----------|
| Switch Category | Texto do botão assist para trocar categorias (requer Core Engine) |
