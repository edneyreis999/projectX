# Plugin Commands: Actor

---

## Actor: Change Equip Slots

Força a mudança dos slots de equipamento do(s) actor(s). Estas mudanças persistem através de mudanças de classe.

**Parâmetros**:
- **Actor ID(s)**: Selecione quais Actor IDs afetar
- **Equip Slots**: Insira os equip slots desejados (case-sensitive, devem corresponder aos nomes em Database > Types)

---

## Actor: Reset Equip Slots

Reseta quaisquer equip slots forçados para o(s) actor(s). Equip slots voltam a ser baseados na classe.

**Parâmetros**:
- **Actor ID(s)**: Selecione quais Actor IDs afetar
