# Plugin Commands: Shop

---

## Shop: Advanced

Alternativa ao "Shop Processing" do editor, facilitando a montagem de inventários para shop usando ranges de IDs ao invés de adicionar items um por um.

**AVISO**: Não permite preços específicos por evento.

### Parâmetros

| Parâmetro | Descrição |
|-----------|-----------|
| Step 1: Item ID's | Selecione ranges de Item IDs para adicionar |
| Step 2: Weapon ID's | Selecione ranges de Weapon IDs para adicionar |
| Step 3: Armor ID's | Selecione ranges de Armor IDs para adicionar |
| Step 4: Purchase Only? | Tornar o shop somente compra? |

### Opcional

| Parâmetro | Descrição |
|-----------|-----------|
| Blacklist | Lista de categorias para blacklistar (marcar items com `<Category: x>`) |
| Whitelist | Lista de categorias para whitelistrar (marcar items com `<Category: x>`) |
