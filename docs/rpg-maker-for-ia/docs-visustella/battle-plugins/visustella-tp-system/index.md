# Enhanced TP System - VisuStella MZ

**Plugin:** VisuStella MZ Enhanced TP System
**Versão:** 1.17
**Tier:** 2
**Autor:** Team VisuStella (Yanfly, Arisu, Olivia, Irina)

## Sobre Esta Documentação

Esta documentação está organizada para facilitar navegação e recuperação de informações sobre o Enhanced TP System. O sistema permite controle total sobre como TP é ganho, modos de TP customizáveis, e gestão de gauge.
