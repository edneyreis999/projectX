# Glossario

| Termo | Abreviacao | Descricao |
|-------|-----------|-----------|
| Ability Points | AP | Recurso de ator usado como moeda para aprender skills |
| Skill Points | SP | Recurso de ator usado como moeda para aprender skills |
| Class Points | CP | Recurso do ClassChangeSystem, usavel como custo |
| Job Points | JP | Recurso do ClassChangeSystem, usavel como custo |
| Show Condition | - | Determina se skill aparece no menu (invisivel se nao atendida) |
| Require Condition | - | Determina se skill esta habilitada no menu (desabilitada se nao atendida) |
| Skill Learn System | SLS | Nome do sistema introduzido por este plugin |
| Tier | - | Nivel hierarquico do plugin VisuStella (0-5) |
| Notetag | - | Tag especial no campo Note do database para configurar plugins |
| Plugin Command | - | Comando de evento que chama funcionalidade do plugin |
| Detail Window | - | Janela que mostra custos e requisitos detalhados |
| Confirm Window | - | Janela de confirmacao antes de aprender uma skill |
| Victory Aftermath | - | Plugin VisuStella que exibe recompensas de batalha |
| Plus | - | Modificador aditivo de ganho (AP/SP) |
| Rate | - | Modificador multiplicativo de ganho (AP/SP) |
| Flat | - | Modificador flat de ganho (AP/SP) |
| JS Notetag | - | Notetag que aceita codigo JavaScript para logica dinamica |

## Text Codes (formatacao)

| Codigo | Descricao |
|--------|-----------|
| `%1` | Primeiro parametro contextual |
| `%2` | Segundo parametro contextual |
| `%3` | Terceiro parametro contextual |
| `%4` | Quarto parametro contextual |

Os parametros variam por campo. Ver cada secao de parametros para os significados especificos.
