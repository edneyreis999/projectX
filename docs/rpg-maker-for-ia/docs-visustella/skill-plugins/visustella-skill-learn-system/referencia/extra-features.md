# Extra Features

O Skill Learn System possui funcionalidades extras quando outros plugins VisuStella estao presentes.

---

## Battle Test

Quando um battle test e iniciado pelo Database, **todas as skills aprendiveis** via notetags do Skill Learn System ficam automaticamente disponiveis para os atores no teste.

**Beneficio**: Reduz a necessidade de adicionar manualmente skills nos atores para testes de batalha.

---

## Victory Aftermath (VisuMZ_3_VictoryAftermath)

Se o plugin Victory Aftermath estiver instalado:

- A quantidade de **AP** e **SP** ganhos e exibida na janela de recompensas.
- Pode ser configurado para aparecer como recurso principal nas janelas dos atores.
- Configuracoes em Plugin Parameters > AP/SP Settings > Victory.
