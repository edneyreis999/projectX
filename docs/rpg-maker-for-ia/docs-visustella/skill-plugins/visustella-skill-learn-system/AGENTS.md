# VisuStella Skill Learn System

## Proposito

Documentacao do plugin VisuStella Skill Learn System (Tier 2) para RPG Maker MZ. Permite atores aprenderem skills via menu dedicado gastando AP, SP, Gold, Items e outros recursos.

## Principais Areas

- **conceitos/**: Visao geral, mecanicas de AP/SP, pipeline de aprendizado
- **notetags/**: Todas as notetags organizadas por categoria (AP, SP, custos, condicoes, animacao)
- **comandos/**: Plugin Commands para AP, SP e sistema
- **parametros/**: Configuracao geral, animacao, som, janelas, AP/SP settings
- **referencia/**: Extra features, compatibilidade, glossario, API JavaScript

## Arquivos Importantes

- `conceitos/aprendizado-de-skills.md` - Pipeline completo de Show/Require/Cost/Confirm
- `notetags/referencia-rapida.md` - Tabela de todas as notetags por destinatario
- `referencia/api-javascript.md` - Variaveis disponiveis em JS notetags
- `referencia/compatibilidade.md` - Integracao com ClassChangeSystem e VictoryAftermath

## Ordem de Navegacao

1. `conceitos/visao-geral.md` (introducao)
2. `conceitos/aprendizado-de-skills.md` (mecanica)
3. `notetags/referencia-rapida.md` (referencia)
4. Demais conforme necessidade

## Contexto do Projeto

- Plugin: VisuStella MZ Skill Learn System
- Tier: 2
