# Parametros - Configuracao Geral

## General Settings

### Visual

- **Displayed Costs**: Quais custos exibir na entrada da skill e em qual ordem. Opcoes: AP, SP, Item, Weapon, Armor, Gold.
- **Separate Skill Type?**: Separar skills aprendiveis por tipo de skill.
- **Hide Learned Skills**: Esconder skills apos serem aprendidas.
- **JS: Draw Status**: Codigo JavaScript para desenhar em Window_SkillStatus quando o Skill Learn System esta ativo.

### Vocabulary

- **Learned Text**: Texto que aparece quando a skill ja foi aprendida. Aceita text codes.

#### Requirements (Sub-grupo)
- **Requirement Header**: Cabecalho para requisitos. `%1` = Requisitos (todos).
- **Separation Format**: Separacao entre requisitos. `%1` = Anterior, `%2` = Proximo.
- **Level Format**: Exibicao de nivel. `%1` = Nivel, `%2` = Texto completo, `%3` = Abreviacao.
- **Skill Format**: Exibicao de skill requerida. `%1` = Icone, `%2` = Nome.
- **Switch Format**: Exibicao de switch requerido. `%1` = Nome do switch.

#### Costs (Sub-grupo)
- **Separation Format**: Separacao entre custos. `%1` = Anterior, `%2` = Proximo.
- **Item Format**: Exibicao de item como custo. `%1` = Qtd, `%2` = Icone, `%3` = Nome.
- **Weapon Format**: Exibicao de arma como custo. `%1` = Qtd, `%2` = Icone, `%3` = Nome.
- **Armor Format**: Exibicao de equipamento como custo. `%1` = Qtd, `%2` = Icone, `%3` = Nome.
- **Gold Format**: Exibicao de gold como custo. `%1` = Qtd, `%2` = Icone, `%3` = Moeda.

---

## Main Access Settings

- **Command Name**: Nome do comando "Skill Learn" no menu.
- **Icon**: Icone para representar Skill Learn.
- **Show in Menu?**: Adicionar o comando "Skill Learn" ao menu por padrao.
