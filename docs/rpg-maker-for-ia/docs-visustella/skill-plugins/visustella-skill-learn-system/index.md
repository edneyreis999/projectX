# VisuStella Skill Learn System - Indice

## Visao Geral

Documentacao catalogada do **VisuStella Skill Learn System** (Tier 2) para RPG Maker MZ.
Plugin que permite atores aprenderem skills via menu dedicado, gastando recursos como AP, SP, Gold, Items e mais.
