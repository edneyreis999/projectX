# Plugin Parameters - Vocabulary Settings

Configurações de texto e formatação exibida pelo plugin.

## Scene_Skill

| Parâmetro | Descrição |
|-----------|-----------|
| Command Name | Texto do comando Passives |
| → Command Icon | Ícone do comando |
| Capacity Text | Texto para "Capacidade" |
| → Capacity Icon | Ícone de capacidade |
| → Capacity Format | `%1` Current, `%2` Max, `%3` Icon |
| Cost Format | `%1` Cost, `%2` Icon |
| → Unlearned Text | Texto para passivos não aprendidos (em vez de custo) |

## Shop Status Window

| Parâmetro | Descrição |
|-----------|-----------|
| Shop Status Text | Texto para passivos no status de loja |
| | Requer VisuMZ_1_ItemsEquipsCore |

## Help Window

| Parâmetro | Descrição |
|-----------|-----------|
| Description Format | `%1` Unlocking Conditions |
| Word Wrap? | Aplica word wrap nas condições |
| | Requer VisuMZ_1_MessageCore |
| Spacing? | Espaçamento entre condições |
| → Spacer | Texto inserido entre condições |
| Empty Descriptions | Texto quando não há condições |
