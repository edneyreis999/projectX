# Plugin Commands - Actor

Comandos de plugin direcionados a atores específicos.

## Actor: Learn Equippable Passive

Força o aprendizado de passivos em actor(s) específico(s).

**Parâmetros**:
| Parâmetro | Descrição |
|-----------|-----------|
| Actor ID(s) | ID(s) dos atores afetados |
| Passive State ID(s) | ID(s) dos states passivos a aprender |
| Show Text Popup? | Mostra popup de texto ao aprender? |

## Actor: Forget Equippable Passive

Remove passivos já aprendidos de actor(s) específico(s).

**Parâmetros**:
| Parâmetro | Descrição |
|-----------|-----------|
| Actor ID(s) | ID(s) dos atores afetados |
| Passive State ID(s) | ID(s) dos states passivos a esquecer |

## Actor: Add Unlearned Equippable Passive

Adiciona passivos à lista de learnable (não aprendidos) de actor(s) específico(s).

**Parâmetros**:
| Parâmetro | Descrição |
|-----------|-----------|
| Actor ID(s) | ID(s) dos atores afetados |
| Passive State ID(s) | ID(s) dos states a adicionar como unlearned |

## Actor: Remove Unlearned Equippable Passive

Remove passivos da lista de learnable de actor(s) específico(s).

**Parâmetros**:
| Parâmetro | Descrição |
|-----------|-----------|
| Actor ID(s) | ID(s) dos atores afetados |
| Passive State ID(s) | ID(s) dos states a remover da lista unlearned |
