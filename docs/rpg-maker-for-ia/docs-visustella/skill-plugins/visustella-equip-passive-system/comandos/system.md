# Plugin Commands - System

Comandos de plugin para controle do sistema de passivos.

## System: Show Passives in Skill Scene?

Controla a visibilidade do comando "Passives" na Skill Scene via evento.

**Parâmetros**:
| Parâmetro | Descrição |
|-----------|-----------|
| Show/Hide? | Mostra ou oculta o comando Passives |

### Casos de Uso

- **Tutorial**: Ocultar passivos até que o jogador aprenda sobre o sistema
- **Desbloqueio progressivo**: Mostrar apenas após evento específico
- **Cena específica**: Temporariamente ocultar durante cutscenes
- **Toggle por switch**: Combinar com switch conditions para controle dinâmico
