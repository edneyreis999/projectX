# Configuração Geral — VisuStella Skill Shop

## General Settings

### Default Skill Cost

| Propriedade | Descrição |
|-------------|-----------|
| **Tipo** | Número |
| **Descrição** | Custo padrão de skills que **não** possuem a notetag `<Skill Shop Cost: x>` |

---

## Background Settings

Configurações visuais do fundo da cena `Scene_SkillShop`.

| Propriedade | Tipo | Descrição |
|-------------|------|-----------|
| **Snapshot Opacity** | número | Opacidade do snapshot de fundo da cena |
| **Background 1** | texto (filename) | Imagem de fundo inferior. Vazio = sem imagem |
| **Background 2** | texto (filename) | Imagem de fundo superior. Vazio = sem imagem |
