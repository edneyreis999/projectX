# Vocabulário — VisuStella Skill Shop

Textos customizáveis exibidos na interface da Skill Shop. Todos aceitam Text Codes do RPG Maker MZ.

---

## Command Window

| Propriedade | Descrição |
|-------------|-----------|
| **Learn Text** | Texto do botão "Aprender" |
| **Learn Icon** | Ícone do botão "Aprender" |
| **Learn Help Description** | Texto de ajuda ao selecionar "Aprender" |
| **Exit Text** | Texto do botão "Sair" |
| **Exit Icon** | Ícone do botão "Sair" |
| **Exit Help Description** | Texto de ajuda ao selecionar "Sair" |

---

## Actor List Window

| Propriedade | Descrição |
|-------------|-----------|
| **Help Description** | Texto de ajuda da lista de atores. Placeholders: `%1` (Nome), `%2` (Nível), `%3` (Classe), `%4` (Skill Types) |
| **Skill Type Joiner** | Texto usado para separar os tipos de skill no help description |
| **Joiner Space** | Adiciona espaço após o joiner |

---

## Skill List Window

| Propriedade | Descrição | Placeholders |
|-------------|-----------|--------------|
| **Already Learned** | Texto para skill já aprendida | — |
| **No SType Access** | Skill sem acesso ao tipo | `%1` = Nome do Skill Type |
| **Wrong Class** | Classe do ator não compatível | `%1` = Classe atual do ator |
| **For Class** | Classe necessária para a skill | `%1` = Nome da classe requerida |
| **Level Requirement** | Nível insuficiente | `%1` = Nível necessário |
| **Learned Skill** | Skill prévia não aprendida | `%1` = Nome da skill, `%2` = Ícone |
