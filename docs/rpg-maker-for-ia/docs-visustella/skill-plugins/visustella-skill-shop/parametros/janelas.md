# Janelas — VisuStella Skill Shop

Configurações de dimensão, estilo e opções visuais das janelas da cena Skill Shop.

---

## Help Window

| Propriedade | Descrição |
|-------------|-----------|
| **Background Type** | Tipo de fundo da janela |

---

## Gold Window

| Propriedade | Descrição |
|-------------|-----------|
| **Background Type** | Tipo de fundo da janela |
| **JS: X, Y, W, H** | Código JavaScript para calcular posição e dimensões |

---

## Command Window

| Propriedade | Descrição |
|-------------|-----------|
| **Background Type** | Tipo de fundo da janela |
| **Style** | Estilo de desenho dos comandos |
| **JS: X, Y, W, H** | Código JavaScript para calcular posição e dimensões |

---

## Actor List Window

| Propriedade | Descrição |
|-------------|-----------|
| **Background Type** | Tipo de fundo da janela |
| **Draw Actor Face?** | Desenha o face do ator |
| **Draw Actor Name?** | Desenha o nome do ator |
| **Draw Actor Class?** | Desenha a classe do ator (não exibido se resolução muito pequena) |
| **JS: X, Y, W, H** | Código JavaScript para calcular posição e dimensões |
