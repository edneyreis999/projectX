# Plugin Parameters - General Settings

## Visão Geral

Estas são as configurações gerais que se aplicam a todos os usos de Dragonbones através deste plugin. Embora a maioria possa permanecer inalterada, aqueles que desejam customizar a natureza do plugin podem fazê-lo através destes Plugin Parameters.

---

## Assets Path

**Descrição**: O caminho do arquivo para o diretório que abriga todos os arquivos Dragonbone.

**Uso**: Define onde os arquivos de assets Dragonbones estão localizados no projeto.

---

## Defaults

### Loaded Animation

**Descrição**: A animação padrão para reproduzir assim que uma armature Dragonbones é carregada.

**Uso**: Define qual animação tocar inicialmente. Geralmente 'idle'.

### Looping Animations

**Descrição**: Força estas animações a se tornarem animações em loop mesmo se não fizerem loop no Dragonbones.

**Uso**: Lista de animações que devem sempre repetir, separadas por vírgulas.

---

## Skeletal Data

### Key

**Descrição**: Chave usada para determinar onde os dados necessários são armazenados.

### Extension

**Descrição**: Extensão usada para determinar quais arquivos contêm os dados necessários.

**Padrão**: `_ske.json`
