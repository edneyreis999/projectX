# Plugin Commands - Introdução

## Visão Geral

Os seguintes Plugin Commands vêm com este plugin. Eles podem ser acessados através do comando de evento **Plugin Command** no RPG Maker MZ.

## Categorias de Comandos

O plugin oferece três categorias principais de Plugin Commands:

1. **Battler Plugin Commands** - Para controlar armatures em batalha
2. **Map Sprite Plugin Commands** - Para controlar armatures no mapa
3. **Picture Plugin Commands** - Para controlar armatures em pictures

## Como Acessar

No RPG Maker MZ:
1. Crie um evento
2. Adicione um comando "Plugin Command"
3. Selecione o comando DragonBones desejado
4. Configure os parâmetros

## Quando Usar

- **Notetags** são para configurações estáticas (definidas no database)
- **Plugin Commands** são para mudanças dinâmicas (durante o jogo)

Use Plugin Commands quando você precisa:
- Mudar animações dinamicamente
- Ajustar configurações em tempo de execução
- Controlar armatures baseado em condições do jogo
- Criar sequências de animação complexas
