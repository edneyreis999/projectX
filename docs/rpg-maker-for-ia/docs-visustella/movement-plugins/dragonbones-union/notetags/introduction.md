# Notetags - Introdução

## Visão Geral

Os seguintes notetags foram adicionados através deste plugin. Estes notetags **não funcionarão** em seu jogo se este plugin estiver **OFF ou não presente**.

## Tipos de Notetags

Este plugin oferece dois tipos principais de notetags:

1. **Dragonbones Battler Notetags** - Para Actors e Enemies na batalha
2. **Dragonbones Map Sprite Notetags & Comment Tags** - Para Actors e Events no mapa

## Como Usar Notetags

No RPG Maker MZ, notetags são colocados na caixa de "Notes" de:

- **Actors** (database → Actors)
- **Enemies** (database → Enemies)
- **Events** (mapa → event → edit → pages)

## Comment Tags vs Notetags

Para **Events**, você pode usar tanto notetags quanto comment tags:

- **Notetags**: Colocados na caixa "Notes" do evento (afeta todas as páginas)
- **Comment Tags**: Colocados como comentários dentro de uma página de evento (afeta apenas aquela página)

**Aviso**: Comentários contêm uma contagem máxima de linhas de 6. Seja cauteloso ao usar Comment Tags para páginas de evento.
