## Recursos de Ajuda

### Debug Mode
Ative debug mode no RPG Maker MZ para informações detalhadas:
1. Test Play (F12)
2. Abrir console (F8)
3. Procurar erros relacionados a ATB

### Plugin Parameters
Verifique parâmetros do plugin se algo não funcionar:
- "Use Field Gauge?" deve ser true para Field Gauge
- "Show Sprite Gauges" deve ser true para gauges visíveis
- "Stuns Reset Gauge?" afeta comportamento de stuns

### Database Settings
Configurações obrigatórias:
- Database > System 1 > Battle System
- Selecionar: "Time Progress (Active)" ou "Time Progress (Wait)"
