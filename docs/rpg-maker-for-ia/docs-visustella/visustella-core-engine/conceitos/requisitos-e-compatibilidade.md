# Requisitos e Compatibilidade

## Requisitos

- **Engine**: RPG Maker MZ (nao funciona em outras versões do RPG Maker)
- **Tier**: 0 (deve ser colocado ACIMA de todos os outros plugins no Plugin Manager)
- **Ordem de tier**: 0, 1, 2, 3, 4, 5

## Compatibilidade

O Core Engine e o plugin pai (Parent Plugin) do ecossistema VisuStella MZ. Todos os plugins de extensao devem ser colocados ABAIXO do Core Engine no Plugin Manager.

A lista completa de plugins de extensao esta em [extension-plugins.md](../referencia/extension-plugins.md).

## Plugins de Extensao por Categoria

### Battle System
- Battle System - BTB, CTB, ETB, FTB, OTB, PTB, STB
- Battle Core (com Action Sequences)

### Battle UI & Visuals
- Frontview Battle UI, Sideview Battle UI
- Visual Cutin Effect, Visual Gauge Styles, Visual State Effects
- Visual Novel Picture Busts

### Battle Mechanics
- Auto Skill Trigger, Boost Action, Chain Battles
- Anti-Damage Barriers, Battle Voices, Battle A.I.

### Equipment & Skills
- Equip Battle Skills, Equip Medal System, Equip Passive System
- Equipment Set Bonuses, Skill Mastery, Item Amplify Skills

### Systems
- Challenge System, Character Creation System, Date and Time System
- Enemy Levels, Field Skills, Furniture System
- More Currencies, QTE and Trigger System, Tile Grafter System

### Audio & Visual Effects
- Action Sequence Camera, Impact, Projectiles
- Lighting Effects, Movement Effects, Picture Effects, Weather Effects

### UI & Menus
- Shop Bust Style UI, Options Core

### Shop & Voice
- Shop Bust Style UI, Voice Acting Control
