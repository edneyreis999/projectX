# Comandos: Debug e Exportacao

## Debug: Current Controller ID
- **PLAY TEST ONLY**
- Mostra controller ID atual no debug console
- Pressionar tecla keyboard apaga os dados
- Copia para clipboard se possivel

## Export: All Maps Text
- **PLAY TEST ONLY**
- Exporta texto de todos os mapas, eventos, paginas e Common Events
- Inclui: Show Text, Show Choices, Show Scrolling Text, Comments
- Apenas texto bruto

## Export: All Troops Text
- **PLAY TEST ONLY**
- Exporta texto de todos os troops, paginas e Common Events associados
- Mesmo formato de exportacao que All Maps Text

## Export: Current Map Text
- **PLAY TEST ONLY**
- Exporta texto do mapa atual, eventos e Common Events
- Nao funciona fora de batalha (mapa deve estar ativo)

## Export: Current Troop Text
- **PLAY TEST ONLY**
- Exporta texto do troop atual e Common Events associados
- Nao funciona fora de batalha
