# Comandos: System

## System: Battle System Change
Troca battle system in-game.
- **Change To**:
  - Database Default
  - DTB: Default Turn Battle
  - TPB Active: Time Progress Battle (Active)
  - TPB Wait: Time Progress Battle (Wait)
  - BTB: Brave Turn Battle (Req VisuMZ_2_BattleSystemBTB)
  - CTB: Charge Turn Battle (Req VisuMZ_2_BattleSystemCTB)
  - OTB: Order Turn Battle (Req VisuMZ_2_BattleSystemOTB)
  - STB: Standard Turn Battle (Req VisuMZ_2_BattleSystemSTB)

## System: Load Images
Pre-load de imagens por pasta. Suporta:
- img/animations/, img/battlebacks1/, img/battlebacks2/, img/enemies/, img/faces/, img/parallaxes/, img/pictures/, img/sv_actors/, img/sv_enemies/, img/system/, img/tilesets/, img/titles1/, img/titles2/

## System: Main Font Size
Muda o font size principal do jogo.
- **Change To**: Novo tamanho da fonte

## System: Side View Battle
Troca entre Front View e Side View.
- **Change To**: Front View ou Side View

## System: Window Padding
Muda o padding padrao das janelas.
- **Change To**: Novo valor de padding
