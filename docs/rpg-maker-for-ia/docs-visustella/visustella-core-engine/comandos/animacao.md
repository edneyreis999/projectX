# Comandos: Animacao

## Animation: Play at Coordinate
Toca uma animacao na tela em coordenada x,y especifica, mesmo sem sprite.

**Parametros:**
- **Animation ID**: Qual animacao tocar
- **X / Y**: Coordenadas. Suporta JavaScript code
- **Mirror Animation?**: Espelhar animacao?
- **Mute Animation?**: Mutar animacao?
