# Comandos: Game, Gold e Map

## Game: Open URL
Abre uma URL a partir do jogo.
- **URL**: Para onde levar o jogador

## Gold: Gain/Lose
Adiciona/remove gold alem do limite do event editor.
- **Value**: Quanto gold ganhar/perder. Negativo = remover.

## Map: Once Parallel
Roda um Common Event em paralelo uma unica vez sem repetir.
- **Common Event ID**: ID do Common Event paralelo
- NAO repete ao terminar
- Limpo ao sair do mapa ou trocar de mapa
- Nao e salvo em memoria
- **Map only!** (nao funciona em batalha sem Battle Core)
