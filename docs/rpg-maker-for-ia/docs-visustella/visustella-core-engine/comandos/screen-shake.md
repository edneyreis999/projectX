# Comandos: Screen Shake

## Screen Shake: Custom
Cria screen shake customizado e define o estilo para proximos shakes.

**Parametros:**
- **Shake Style**: Original / Random / Horizontal / Vertical
- **Power**: Nivel de potencia
- **Speed**: Nivel de velocidade
- **Duration**: Duracao. Suporta JS code.
- **Wait for Completion**: Esperar terminar?
