# Plugin Parameters: Image Loading

RPG Maker MZ usa carregamento assincrono - imagens sao carregadas quando necessarias. Isso causa delays. Imagens pre-carregadas ficam disponiveis imediatamente (enquanto estiverem no cache).

## Pastas Disponiveis para Preload

Configure quais arquivos carregar ao iniciar o jogo:

| Pasta | Conteudo |
|-------|----------|
| img/animations/ | Animacoes Effekseer |
| img/battlebacks1/ | Backgrounds de batalha (camada 1) |
| img/battlebacks2/ | Backgrounds de batalha (camada 2) |
| img/enemies/ | Imagens de inimigos (front view) |
| img/faces/ | Faces dos personagens |
| img/parallaxes/ | Parallaxes de mapa |
| img/pictures/ | Pictures (show picture event) |
| img/sv_actors/ | Sprites de atores (side view) |
| img/sv_enemies/ | Sprites de inimigos (side view) |
| img/system/ | Imagens de sistema |
| img/tilesets/ | Tilesets |
| img/titles1/ | Title screen (camada 1) |
| img/titles2/ | Title screen (camada 2) |

Tambem disponivel via Plugin Command "System: Load Images" para carregar em qualquer momento.
