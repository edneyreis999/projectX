# Plugin Parameters: Keyboard Input Settings

Configuracoes de input via teclado. Testado apenas com teclados ingleses - desativar se nao for compativel com o idioma do jogo.

Se um controller estiver conectado ao entrar na tela de nome, usara modo manual em vez de keyboard. Se um botao de controller for pressionado durante modo keyboard, troca automaticamente para manual.

## Controls

- **WASD Movement**: Habilita movimento WASD. Move botao W (page down) para E.
- **R Button: Dash Toggle**: R como toggle para Always Dash.

## Name Input

- **Enable?**: Habilita input de teclado para entrada de nome
- **Default Mode**: Default (setas) ou Keyboard (digitar)
- **QWERTY Layout**: Usa layout QWERTY para entrada manual
- **Keyboard Message**: Mensagem exibida ao permitir keyboard entry. Suporta text codes.
- **Banned Words**: Palavras proibidas para nomes (inclui substrings). Buzzer sound ao usar.

## Number Input

- **Enable?**: Habilita input de teclado para entrada de numeros

## Button Assist (Name Input)

- **Finish Entry**: Texto para descrever finalizar entrada
- **Page Change**: Texto para descrever troca de pagina
- **Switch to Keyboard**: Texto para trocar para teclado
- **Switch to Manual**: Texto para trocar para manual
