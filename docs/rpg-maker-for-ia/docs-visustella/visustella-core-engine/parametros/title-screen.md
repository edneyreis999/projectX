# Plugin Parameters: Title Screen Settings

## Title Command List Settings

Comandos customizaveis para title screen. Requer conhecimento JavaScript.

### Title Command
- **Symbol**: Identificador do comando
- **STR: Text**: Texto exibido (se preenchido, ignora JS: Text)
- **JS: Text**: Codigo JavaScript para texto exibido
- **JS: Show**: Codigo para determinar visibilidade
- **JS: Enable**: Codigo para determinar se habilitado
- **JS: Ext**: Dados extras
- **JS: Run Code**: Codigo executado ao selecionar comando

## Title Picture Buttons Settings

Botoes de imagem no title screen que abrem URLs externas.

### Settings
- **Picture's Filename**: Arquivo de imagem do botao
- **Button URL**: URL aberta ao clicar
- **JS: Position**: Codigo para posicao do botao
- **JS: On Load**: Codigo executado ao carregar bitmap
- **JS: Run Code**: Codigo executado ao pressionar botao
