# Plugin Parameters: Gold Settings

Configuracao da moeda principal do jogo.

| Parametro | Default | Descricao |
|-----------|---------|-----------|
| Gold Max | 99999999 | Quantidade maxima de gold que o party pode carregar |
| Gold Font Size | 26 | Tamanho da fonte para exibir gold |
| Gold Icon | 0 | Icon para representar gold (0 = sem icon) |
| Gold Overlap | - | Texto exibido quando gold excede o espaco da janela |
