# Plugin Parameters: UI Settings

Ajustes de como objetos in-game e menus sao exibidos.

## UI Area

| Parametro | Descricao |
|-----------|-----------|
| Fade Speed | Velocidade de fade para transicoes |
| Box Margin | Margem em pixels para bordas da tela |
| Command Window Width | Largura de Command Windows padrao |
| Bottom Help Window | Help Window na base da tela |
| Right Aligned Menus | Command windows alinhados a direita |
| Show Buttons | Exibir botoes clicaveis no jogo |
| Show Cancel/Menu/Page/Number Buttons | Botoes individuais (requer Show Buttons ON) |
| Button Area Height | Altura da area de botoes |
| Bottom Buttons | Botoes na base da tela |
| Side Buttons | Empurrar botoes para lateral se houver espaco |
| State Icons Non-Frame | Substituir sprite frame por non-frame (melhor com icons em zoom) |

## Menu Objects

- **Level -> EXP Gauge**: Desenhar EXP Gauge sob o level
- **Parameter Arrow**: Seta usada para mudancas de parametro

## Text Code Support

- **Class Names**: Nomes de classes suportam text codes
- **Nicknames**: Apelidos suportam text codes
