# Notetags: Atores e Classes

## Atores

### `<Max Level: x>`
- **Usado em**: Actor Notetags
- Determina o level maximo do ator
- Permite ultrapassar o limite de 99 do editor
- Se nao usado, usa o valor do database

### `<Initial Level: x>`
- **Usado em**: Actor Notetags
- Determina o level inicial do ator
- Permite ultrapassar o limite de 99 do editor
- Se nao usado, usa o valor do database

## Classes

### `<Learn At Level: x>`
- **Usado em**: Class Skill Learn Notetags
- Determina em qual level a classe aprende a skill associada
- Permite ultrapassar o limite de 99 do editor
- Se nao usado, usa o valor do database

## Notas
- Os limites do database (99) sao do editor RPG Maker MZ
- Estas notetags permitem valores maiores na engine
- Os Plugin Parameters de Parameter Settings tambem podem ajustar caps
