# Notetags: Quality of Life

## Minimum Encounter Steps

### `<Minimum Encounter Steps: x>`
- **Usado em**: Map Notetags
- Define o numero minimo de passos apos uma batalha antes de poder ter outro encounter
- Se nao usado, usa QoL Settings > Encounter Rate Min

## Tile Shadows

### `<Show Tile Shadows>` / `<Hide Tile Shadows>`
- **Usado em**: Map Notetags
- Controla sombras de tiles no mapa especifico
- Se nao usado, usa QoL Settings > No Tile Shadows

## Scroll Lock

### `<Scroll Lock X>` / `<Scroll Lock Y>`
- **Usado em**: Map Notetags
- Previne scroll horizontal (X) ou vertical (Y) do mapa
- Util para mapas levemente menores que a resolucao
- Usa display nudge dos Plugin Parameters
- Desabilitado se o mapa esta com zoom

### `<Scroll Lock X: x>` / `<Scroll Lock Y: y>`
- **Usado em**: Map Notetags
- Scroll lock com nudge customizado
- Valores entre 0 e 1 representam quanto nudge aplicar
- Exemplo: para 1280x720, mapa de 27 tiles beneficia de nudge 0.15625
- Desabilitado se o mapa esta com zoom
