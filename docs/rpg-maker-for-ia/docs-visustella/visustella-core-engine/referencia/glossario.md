# Glossario

## Termos do Plugin

| Termo | Significado |
|-------|-------------|
| Tier 0 | Nivel de prioridade do plugin. Core Engine e Tier 0 (mais alto). |
| Parent Plugin | Plugin pai. Extension plugins dependem do Core Engine. |
| Extension Plugin | Plugin que requer o Core Engine. |
| QoL | Quality of Life - melhorias de jogabilidade. |
| DTB | Default Turn Battle - sistema de batalha padrao do MZ. |
| TPB | Time Progress Battle - sistema de batalha com barra de tempo. |
| ATB | Active Turn Battle - TPB com VisuStella ATB plugin. |
| BTB | Brave Turn Battle - sistema VisuStella com Brave Points. |
| CTB | Charge Turn Battle - sistema VisuStella com carga. |
| ETB | ... Turn Battle - sistema VisuStella. |
| FTB | Force Turn Battle - sistema VisuStella. |
| OTB | Order Turn Battle - sistema VisuStella. |
| PTB | ... Turn Battle - sistema VisuStella. |
| STB | Standard Turn Battle - sistema VisuStella. |

## Formatos de Cor

| Formato | Exemplo | Uso |
|---------|---------|-----|
| Numero | `0`, `1`, `2` | Cor do Window Skin |
| Hex | `#rrggbb` | Cor customizada |
| RGBA | `rgba(255, 0, 0, 0.5)` | Cor com transparencia |
