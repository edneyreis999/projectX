# Visual Novel Picture Busts - VisuStella MZ

Documentação catalogada do plugin Visual Novel Picture Busts para RPG Maker MZ.

## Sobre

Permite usar Pictures como busts no estilo Visual Novels com comandos simplificados para entrada, saída, troca de expressões, fade, movimento, escala, animações contínuas e alteração de tom.

- **Tier**: 2
- **Requisito**: Core Engine VisuStella MZ
