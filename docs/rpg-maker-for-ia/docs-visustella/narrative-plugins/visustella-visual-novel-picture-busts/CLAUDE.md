# Visual Novel Picture Busts - VisuStella MZ

Plugin para Picture Busts estilo Visual Novel no RPG Maker MZ.

## Propósito

Sistema de busts para diálogos e narrativas visuais. Busts são Pictures com comandos simplificados para posicionamento (0-10), entrada/saída com fade, troca de expressões, espelhamento, escala, animações contínuas (breathing, fidgeting, swaying) e alteração de tom/tint.

## Principais Áreas

- **[conceitos/](conceitos/)** — Como busts funcionam: Pictures, IDs, âncora, positions
- **[comandos/](comandos/)** — 6 categorias: básicos, fade, movimento, escala, animações, tone/tint
- **[parametros/](parametros/)** — Configuração global: anchor, scale, positioning, tone
- **[referencia/](referencia/)** — Glossário e compatibilidade
