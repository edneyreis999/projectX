# Comandos de Animações (Breathing, Fidgeting, Swaying)

Efeitos de animação contínua para dar vida aos busts.

Todos os campos "Picture ID(s)" aceitam código JavaScript.

---

## BREATHING: Start

Inicia efeito de respiração no(s) bust(s). Faz o gráfico parecer mais vivo.

| Parâmetro | Descrição |
|-----------|-----------|
| **Picture ID(s)** | ID(s) da(s) Picture(s). Aceita JS. |
| **Speed X / Speed Y** | Velocidade do ciclo de respiração horizontal/vertical. Maior = mais lento. Aceita JS. |
| **Rate X / Rate Y** | Taxa do ciclo de respiração. Determina quantidade de mudança. Aceita JS. |

---

## BREATHING: Stop

Para o efeito de respiração no(s) bust(s). O gráfico fica estático.

| Parâmetro | Descrição |
|-----------|-----------|
| **Picture ID(s)** | ID(s) da(s) Picture(s). Aceita JS. |

---

## FIDGETING: Start

Inicia efeito de inquietação no(s) bust(s). O gráfico se move para frente e trás.

| Parâmetro | Descrição |
|-----------|-----------|
| **Picture ID(s)** | ID(s) da(s) Picture(s). Aceita JS. |
| **Speed X / Speed Y** | Velocidade do ciclo horizontal/vertical. Maior = mais lento. Aceita JS. |
| **Distance X / Distance Y** | Distância máxima do ciclo horizontal/vertical. Determina quantidade de mudança. Aceita JS. |

---

## FIDGETING: Stop

Para o efeito de inquietação no(s) bust(s). O gráfico fica estacionário.

| Parâmetro | Descrição |
|-----------|-----------|
| **Picture ID(s)** | ID(s) da(s) Picture(s). Aceita JS. |

---

## SWAYING: Start

Inicia efeito de balanço no(s) bust(s). O gráfico oscila angularmente.

| Parâmetro | Descrição |
|-----------|-----------|
| **Picture ID(s)** | ID(s) da(s) Picture(s). Aceita JS. |
| **Angle Speed** | Velocidade do ciclo de balanço. Maior = mais lento. Aceita JS. |
| **Angle Sway** | Ângulo máximo do ciclo. Determina quantidade de mudança. Aceita JS. |

---

## SWAYING: Stop

Para o efeito de balanço no(s) bust(s). O gráfico fica estacionário.

| Parâmetro | Descrição |
|-----------|-----------|
| **Picture ID(s)** | ID(s) da(s) Picture(s). Aceita JS. |
