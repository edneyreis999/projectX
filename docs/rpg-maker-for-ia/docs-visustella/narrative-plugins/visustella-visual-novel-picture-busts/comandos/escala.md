# Comandos de Escala

Comandos para escalar busts (ampliar/reduzir).

**Escala de valores**: 100 = 100% = 1.0

Todos os campos "Picture ID(s)" aceitam código JavaScript.

---

## SCALE: Scale Bust(s) By

Escala bust(s) por valores aditivos.

| Parâmetro | Descrição |
|-----------|-----------|
| **Picture ID(s)** | ID(s) da(s) Picture(s). Aceita JS. |
| **Scale X By** | Alterar (aditivamente) o valor de escala X. Aceita JS. |
| **Scale Y By** | Alterar (aditivamente) o valor de escala Y. Aceita JS. |
| **Duration** | Duração em frames para a escala |

---

## SCALE: Scale Bust(s) To

Escala bust(s) para valores específicos.

| Parâmetro | Descrição |
|-----------|-----------|
| **Picture ID(s)** | ID(s) da(s) Picture(s). Aceita JS. |
| **Scale X By** | Definir escala X para este valor. "Unchanged" sem mudanças. Aceita JS. |
| **Scale Y By** | Definir escala Y para este valor. "Unchanged" sem mudanças. Aceita JS. |
| **Duration** | Duração em frames para a escala |

---

## SCALE: Scale Reset Bust(s)

Reseta a escala do(s) bust(s) para os valores padrão definidos nos Plugin Parameters.

| Parâmetro | Descrição |
|-----------|-----------|
| **Picture ID(s)** | ID(s) da(s) Picture(s). Aceita JS. |
| **Duration** | Duração em frames para a escala |
