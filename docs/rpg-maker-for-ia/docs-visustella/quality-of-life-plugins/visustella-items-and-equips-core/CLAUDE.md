# Items & Equips Core VisuStella MZ

## Propósito

Documentação catalogada do plugin VisuStella Items & Equips Core para RPG Maker MZ. Plugin Tier 1 que melhora as cenas de Item, Equip e Shop com categorias customizadas, notetags avançadas e controle de parâmetros.

## Principais Áreas

- **Conceitos**: Equipment Type Handling, Shop Status Window, Modern Controls
- **Notetags**: Gerais, Item Accessibility, Equipment, Status Window, Shop Menu, JavaScript
- **Comandos**: Actor, Purify, Shop Advanced
- **Parâmetros**: Item Menu, Categories, NEW! Labels, Equip Menu, Shop Menu, Shop Status Window
- **Referência**: Compatibilidade, Extensões, Glossário
