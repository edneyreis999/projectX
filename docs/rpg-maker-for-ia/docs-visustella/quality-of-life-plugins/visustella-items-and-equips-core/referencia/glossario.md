# Glossário

Termos e conceitos usados no Items & Equips Core.

---

## Termos do Plugin

| Termo | Definição |
|-------|-----------|
| **EType** | Equipment Type - Tipo de equipamento definido em Database > Types |
| **AType** | Armor Type - Subtipo de armadura |
| **WType** | Weapon Type - Subtipo de arma |
| **Artifact** | Armadura que não é equipável mas aplica traits/bônus apenas por estar no inventário |
| **Cursed** | Equipamento que não pode ser removido manualmente até purificação |
| **Purify** | Processo de remover maldição de equipamento |
| **Rulings** | Regras sobre quais slots podem ser removidos/otimizados |
| **Shop Status Window** | Janela de status detalhado na Shop Scene |
| **NEW! Label** | Marcador sobre itens recentemente adquiridos |
| **Category** | Agrupamento customizado de itens via notetags |
| **Equip Copy Limit** | Limite de cópias do mesmo equipamento que um ator pode vestir |
| **Equip Type Limit** | Limite de equipamentos do mesmo tipo que podem ser equipados juntos |
| **Base Parameter** | Parâmetro calculado pela classe + bônus permanentes (NÃO é o total) |
