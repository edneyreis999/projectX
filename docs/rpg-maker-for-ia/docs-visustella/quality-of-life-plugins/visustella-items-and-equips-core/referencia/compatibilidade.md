# Compatibilidade

Informações de compatibilidade do Items & Equips Core com outros plugins VisuStella.

---

## Battle Core VisuStella MZ

### Damage Multiplier / Healing Multiplier Vocabulary

Mudar o vocabulário "Damage Multiplier" ou "Healing Multiplier" do Shop Status Window **não** é feito pelos Plugin Parameters do Items & Equips Core quando o Battle Core está instalado.

**Local correto**: Battle Core > Plugin Parameters > Damage Settings > Damage Styles > ajustar "Damage Multiplier"/"Healing Multiplier" do estilo.

**Motivo**: Nem todos os damage styles funcionam com "Multipliers". Cada damage style tem seu próprio vocabulário para ser mais preciso.

### Lembrete

Os Plugin Parameters do Items & Equips Core para essas configurações incluem um lembrete na descrição apontando para o local correto.

---

## Weapon Swap System VisuStella MZ

O recurso de custom equip slots do Items & Equips Core permitia adicionar slots extras de weapons. Com o Weapon Swap System:

- Slots de weapons são **limitados a no máximo 1 por personagem**
- Necessário para viabilizar o sistema de troca de armas
- Weapons **não podem** se tornar cursed quando o Weapon Swap System está instalado
