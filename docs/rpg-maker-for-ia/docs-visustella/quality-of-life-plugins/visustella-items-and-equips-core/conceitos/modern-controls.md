# Modern Controls (Core Engine Compatibility)

## Conceito

Se o VisuStella Core Engine está instalado com **Modern Controls** habilitado, os controles das cenas Item, Equip e Shop mudam.

## Item Menu Scene

- A **Item List Window** fica automaticamente ativa
- Navegação entre categorias:
  - **Left/Right** (coluna única)
  - **Page Up/Page Down** (múltiplas colunas)
- Comportamento similar ao vender itens na Shop Menu Scene

## Equip Menu Scene

- A **Equip Slots Window** fica automaticamente ativa
- A command window só é ativada ao mover para cima até ela

## Requisito

- VisuStella Core Engine instalado
- Plugin Parameter "Modern Controls" habilitado no Core Engine
