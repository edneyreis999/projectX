# Plugin Parameters: Equip Menu Settings

Configurações da cena de Equip Menu.

---

## General

| Parâmetro | Descrição |
|-----------|-----------|
| Use Updated Layout | Usa layout atualizado? Sobrescreve Core Engine settings. |
| Param Font Size | Tamanho da fonte para valores de parâmetros |
| Show Menu Portraits? | Com Main Menu Core, exibe Menu Portraits em vez de face |
| JS: Portrait Upper | Código para desenhar dados superiores com portrait |
| JS: Face Upper | Código para desenhar dados superiores com face |
| JS: Parameter Lower | Código para desenhar parâmetros na parte inferior |
| Layout Style | Upper/Lower Help + Left/Right Input |
| Status Window Width | Largura da janela de status (sem updated layout) |
| Show Back Rectangles? | Retângulos escuros para destacar informação |
| Back Rectangle Color | `#rrggbb` ou número para Window Skin |
| Cursed Equip Popup | Texto popup ao equipar item cursed. Requer Core Engine. `%1`=Ator, `%2`=Equip, `%3`=Icon |

---

## Command Window

| Parâmetro | Descrição |
|-----------|-----------|
| Style | Text Only / Icon Only / Icon + Text / Auto |
| Text Align | Alinhamento do texto |
| Equip Icon | Icon do comando Equip |
| Help Description | Descrição de ajuda do comando Equip (text codes) |
| Add Optimize Command? | Adicionar comando Optimize? |
| Optimize Icon | Icon do comando Optimize |
| Add Clear Command? | Adicionar comando Clear? |
| Clear Icon | Icon do comando Clear |

---

## Remove Equip

| Parâmetro | Descrição |
|-----------|-----------|
| Icon | Icon para remoção de equipamento |
| Text | Texto para remoção de equipamento |
| Use SHIFT Shortcut? | Adicionar botão SHIFT como atalho para remover |

---

## Rulings

| Parâmetro | Descrição |
|-----------|-----------|
| Equip-Adjust HP/MP | Ajustar diferenças de HP/MP após trocar equips com MaxHP/MaxMP |
| Non-Removable Types | IDs de Equipment Types que devem sempre ter item equipado |
| Non-Optimized Types | IDs de Equipment Types ignorados na otimização |

---

## Button Assist Window

| Parâmetro | Descrição |
|-----------|-----------|
| SHIFT: Remove | Texto do botão assist para atalho SHIFT Remove |
