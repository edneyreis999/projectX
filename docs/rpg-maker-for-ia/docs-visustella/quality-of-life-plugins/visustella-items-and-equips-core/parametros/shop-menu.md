# Plugin Parameters: Shop Menu Settings

Configurações da cena de Shop Menu.

---

## General

| Parâmetro | Descrição |
|-----------|-----------|
| Use Updated Layout | Usa layout atualizado? Sobrescreve Core Engine settings. |
| Layout Style | Upper/Lower Help + Left/Right Input |

---

## Switches

| Parâmetro | Descrição |
|-----------|-----------|
| Switch: Buy | Comprar itens liga este Switch. Reverte a OFF ao abrir Shop Scene |
| Switch: Sell | Vender itens liga este Switch. Reverte a OFF ao abrir Shop Scene |

---

## Command Window

| Parâmetro | Descrição |
|-----------|-----------|
| Hide Unavailable? | Ocultar comandos indisponíveis (ex: Purchase Only)? |
| Style | Text Only / Icon Only / Icon + Text / Auto |
| Text Align | Alinhamento do texto |
| Buy Icon | Icon do comando Buy |
| Sell Icon | Icon do comando Sell |
| Cancel Icon | Icon do comando Cancel |
| Rename "Cancel" | Renomear Cancel para algo mais lógico |

---

## Prices

| Parâmetro | Descrição |
|-----------|-----------|
| Sell Price Rate | Taxa padrão do preço de venda |
| JS: Buy Price | Modificações no preço de compra antes de finalizar |
| JS: Sell Price | Modificações no preço de venda antes de finalizar |

---

## Button Assist Window

| Parâmetro | Descrição |
|-----------|-----------|
| Small Increment | Texto para incremento pequeno de quantidade |
| Large Increment | Texto para incremento grande de quantidade |
