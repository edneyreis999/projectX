# Plugin Parameters: NEW! Labels

Configuração do marcador **NEW!** que aparece sobre itens recentemente adquiridos.

---

## Conceito

Quando o jogador recebe novos itens, um marcador **NEW!** pode ser colocado sobre o icon do item ao navegar nos menus. Esta é uma feature de qualidade de vida de RPGs modernos para ajudar jogadores a identificar o que receberam recentemente.

---

## Parâmetros

| Parâmetro | Descrição |
|-----------|-----------|
| Use NEW! Labels? | Ativar/desativar marcadores NEW! |
| Icon | Icon index para representar o texto NEW! (0 = sem icon) |
| Text | Texto do marcador NEW! |
| Font Color | `#rrggbb` para custom ou número para text color do Window Skin |
| Font Size | Tamanho da fonte do texto NEW! |
| Fade Limit | Limite superior de opacidade antes de reverter |
| Fade Speed | Velocidade do fade do marcador |
| Offset X | Deslocamento horizontal do marcador |
| Offset Y | Deslocamento vertical do marcador |
