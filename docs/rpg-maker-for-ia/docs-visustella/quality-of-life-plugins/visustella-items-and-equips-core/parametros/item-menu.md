# Plugin Parameters: Item Menu Settings

Configurações da cena de Item Menu.

---

## General Window

| Parâmetro | Descrição |
|-----------|-----------|
| Use Updated Layout | Usa layout atualizado? Habilita automaticamente o Status Window. Sobrescreve Core Engine settings. |
| Disabled: Vanilla | Se NÃO usar layout atualizado, mantém tudo vanilla puro. Categorias limitadas a 4, sem icons nos nomes, sem Status Window, sem Modern Controls, 2 colunas fixas. |
| Layout Style | Upper/Lower Help + Left/Right Input |

---

## List Window

| Parâmetro | Descrição |
|-----------|-----------|
| Columns | Número máximo de colunas |

---

## Item Quantity

| Parâmetro | Descrição |
|-----------|-----------|
| Item Max | Quantidade máxima padrão para itens |
| Weapon Max | Quantidade máxima padrão para weapons |
| Armor Max | Quantidade máxima padrão para armors |
| Quantity Format | Como exibir quantidade. `%1` = Item Quantity |
| Font Size | Tamanho da fonte para quantidade |

---

## Shop Status Window (no Item Menu)

| Parâmetro | Descrição |
|-----------|-----------|
| Show in Item Menu? | Exibir Shop Status Window no Item Menu? |
| Adjust List Window? | Ajustar automaticamente Item List Window ao usar Status Window? |
| Background Type | 0=Window, 1=Dim, 2=Transparent |
| JS: X, Y, W, H | Código para dimensões do Status Window. Requer "Use Updated Layout" + "Disabled: Vanilla" = false |

---

## Button Assist Window

| Parâmetro | Descrição |
|-----------|-----------|
| Switch Category | Texto do botão assist para trocar categorias (Core Engine) |
