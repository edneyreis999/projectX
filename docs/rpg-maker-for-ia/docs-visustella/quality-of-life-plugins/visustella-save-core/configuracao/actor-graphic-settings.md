# Actor Graphic Settings

## Visão Geral

Configura qual gráfico usar para exibir os atores do grupo no menu de save.

## Opções de Gráfico

| Opção | Descrição |
|---|---|
| **None** | Não exibir nenhum gráfico de ator |
| **Face** | Exibir as face graphics dos atores |
| **Map Sprite** | Exibir os sprites de mapa dos atores |
| **Sideview Battler** | Exibir os gráficos de SV Battler dos atores |

## Observações

- Se existirem saves criados **antes** da instalação do plugin, pode ser necessário salvar sobre os arquivos existentes para que os gráficos de Sideview Battler apareçam corretamente.
- A largura dos sprites e SV Battlers no menu é configurável via **Sprite Width** e **SV Battler Width** nas [Style Settings](style-settings.md).
