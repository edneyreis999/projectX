# VisuStella Debugger

Plugin de debug avançado para RPG Maker MZ que substitui o menu debug padrão (F9) com acesso a Common Events, teleport, batalhas rápidas, ajuste de itens/weapons/armors, self switches, buffs/states e quick commands customizáveis.

## Propósito da Documentação

Referência técnica para uso e configuração do VisuStella Debugger durante desenvolvimento e playtesting.
