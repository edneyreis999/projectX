# Common Events

## Funcionalidade

Permite executar (launch) qualquer Common Event diretamente pelo debug menu durante o jogo.

## Disponibilidade
- **Apenas no Map Scene** (não funciona durante batalha ou menus)

## Uso Prático

- Criar debug commands customizados usando eventos (eventing)
- Testar Common Events sem precisar configurar triggers específicos
- Validar lógica de eventos durante desenvolvimento

## Dica

Combine com o sistema de Quick Commands para ter tanto comandos JS quanto comandos baseados em eventos no seu fluxo de debug.
