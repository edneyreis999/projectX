# Items, Weapons, Armors

## Funcionalidade

Permite ajustar as quantidades de items, weapons e armors que o party possui, incluindo ouro (gold).

## Disponibilidade
- **Qualquer scene**

## Três Menus Separados

| Menu | O que ajusta |
|------|-------------|
| **Items** | Quantidade de cada item no inventário |
| **Weapons** | Quantidade de cada arma (não equipadas) |
| **Armors** | Quantidade de cada armadura (não equipadas) |

## Funcionalidades

### Digitação Direta
Ao passar o mouse sobre a opção central (gold, item, weapon ou armor), é possível **digitar o número exato** desejado.

### Filtro Automático
- Items unnamed são automaticamente **filtrados** da lista
- Items com `-----` no nome também são filtrados
- **Motivo**: Reduzir bloat na lista de debug

### Weapons e Armors — Nota Importante
Os números representam apenas a quantidade **carregada pelo party** (não equipadas). Items equipados **não contam** para a quantidade exibida.

### Gold
É possível alterar a quantidade de ouro que o party possui a partir do mesmo menu.
