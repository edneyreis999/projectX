# Battle Testing

## Funcionalidade

Permite iniciar uma batalha com qualquer Troop configurada, com controle sobre o tipo de iniciativa.

## Disponibilidade
- **Apenas no Map Scene**

## Modificadores de Iniciativa

Ao iniciar a batalha, escolha entre:

| Modificador | Efeito |
|-------------|--------|
| **Preemptive** | Party começa com bônus de iniciativa (turno extra) |
| **Surprise Attack** | Inimigos começam com vantagem (party não age no primeiro turno) |
| **Neither** | Batalha normal sem modificadores |

## Uso

1. Abrir Debug Menu (F9)
2. Selecionar "Battle"
3. Escolher a Troop pelo ID
4. Selecionar o modificador de iniciativa
5. Batalha é iniciada

## Aplicações

- Testar encounters específicos sem precisar caminhar até o mapa
- Verificar balanceamento de troops
- Testar mechanics de preemptive/surprise attack
- Validar visuais de batalha para troops específicas
