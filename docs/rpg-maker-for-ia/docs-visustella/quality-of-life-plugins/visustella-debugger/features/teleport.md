# Teleport

## Funcionalidade

Permite teletransportar o player para qualquer mapa do projeto com posicionamento preciso.

## Disponibilidade
- **Apenas no Map Scene**

## Interface

### Seleção de Mapa
- **Coluna esquerda**: Mapas listados na ordem do editor MZ (organização hierárquica)
- **Coluna direita**: Mapas listados em ordem numérica por Map ID

### Posicionamento
Após selecionar o mapa, escolha a posição exata para colocar o player character.

## Uso

1. Abrir Debug Menu (F9)
2. Selecionar "Teleport"
3. Escolher o mapa (por nome ou por ID)
4. Selecionar a posição no mapa
5. Player é teletransportado imediatamente
