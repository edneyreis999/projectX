# Switches & Variables

## Switches

Menu padrão de ajuste de switches ON/OFF com melhorias visuais.

### Color Coding
- Switches são coloridos para diferenciar [ON] e [OFF]
- Switches unnamed que estão [ON] exibem `! ATTENTION !` como nome
  - **Motivo**: Alertar sobre switches em uso que podem ser sobrescritos acidentalmente em eventos futuros

## Variables

Menu de ajuste de variables com mais flexibilidade que o padrão.

### Diferenças do Padrão
- Incrementos maiores que 1 ou 10 (valores customizáveis)
- Possibilidade de **digitar o valor exato** diretamente ao selecionar a variable
- Variables unnamed com valores não-zero exibem `! ATTENTION !`
  - **Motivo**: Mesmo que switches — evitar override acidental

## Disponibilidade
- Acessível de **qualquer scene**
