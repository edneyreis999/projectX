# Map Events

## Funcionalidade

Permite ajustar Self Switches (A, B, C, D) de eventos do mapa e apagar (erase) eventos.

## Disponibilidade
- **Apenas no Map Scene**

## Self Switches

- Controle dos switches A, B, C, D de cada evento no mapa atual
- Toggle ON/OFF diretamente pelo menu

## Erase Events

- Opção de apagar (erase) eventos do mapa atual
- Equivalente ao comando "Erase Event" do RPG Maker MZ

## Limitações

- **NÃO** controla Self Switches adicionados por outros plugins
- **NÃO** controla Self Variables adicionados por outros plugins
- **Motivo**: Quantidade ilimitada de self switches/variables customizados torna inviável a listagem

## Uso

1. Abrir Debug Menu (F9)
2. Selecionar "Map Events"
3. Escolher o evento
4. Ajustar Self Switches A/B/C/D ou erase o evento
