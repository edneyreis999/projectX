# VisuStella Debugger — Índice

## Visão Geral

O VisuStella Debugger é um plugin Tier 4 para RPG Maker MZ que substitui o menu debug padrão (F9) por uma interface completa de debug, acessível de qualquer scene (não apenas do mapa).
