# Glossário — VisuStella Debugger

| Termo | Definição |
|-------|-----------|
| **Debug Menu** | Interface de debug acessada via tecla F9, substituindo o menu padrão do RPG Maker MZ |
| **Tier 4** | Classificação de prioridade do plugin na lista do Plugin Manager. Plugins de tier menor devem ficar acima |
| **Quick Commands** | Comandos JavaScript customizáveis adicionados via Plugin Parameters para automação de testes |
| **Scene** | Tela/estado atual do jogo (Map Scene, Battle Scene, Menu Scene, etc.) |
| **Self Switch** | Switches A, B, C, D locais de cada evento no mapa |
| **Troop** | Grupo de inimigos configurado no database para encounters de batalha |
| **Preemptive** | Modificador de batalha onde o party age primeiro com vantagem |
| **Surprise Attack** | Modificador de batalha onde os inimigos agem primeiro (penalidade) |
| **Color Coding** | Sistema visual de cores para diferenciar estados ON/OFF de switches e variables |
| **Custom Value** | Valor numérico adicional em states, disponibilizado pelo Skills & States Core |
