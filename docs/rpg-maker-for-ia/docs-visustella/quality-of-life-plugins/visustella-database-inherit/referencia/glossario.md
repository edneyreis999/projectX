# Glossario

| Termo | Definicao |
|-------|-----------|
| **Parent** | Objeto de origem das propriedades. O objeto do qual se herda. |
| **Child** | Objeto que recebe as propriedades. O objeto que contem a notetag de heranca. |
| **Inheritance** | Mecanismo de transferir propriedades de um parent para um child. |
| **Overwrite** | Propriedade do parent substitui a do child. Configuravel via Plugin Parameters. |
| **Extend** | Propriedade do parent e adicionada a do child. Configuravel via Plugin Parameters. |
| **Notetag** | Tag especial no campo Note do RPG Maker MZ que configura o comportamento do plugin. |
| **Meta Flags** | Metadados parseados automaticamente pelo RPG Maker MZ a partir das notetags. |
| **Damage Formula** | Formula JavaScript que calcula dano em Skills e Items. |
| **Parameters** | Valores numericos de atributos (MaxHP, MaxMP, ATK, DEF, MAT, MDF, AGI, LUK). |
| **Action Patterns** | Lista de acoes que um Enemy pode executar em batalha, com condicoes. |
| **Traits** | Propriedades especiais que modificam objetos (resistencias, bonuses, etc.). Usados em Actors, Classes, Weapons, Armors, Skills, States. |
| **Effects** | Efeitos aplicados ao usar Skills e Items ( cura, dano, aplicar state, etc.). |
| **Tier** | Nivel hierarquico do plugin VisuStella. Database Inherit e Tier 4. Deve ficar abaixo de plugins de tier 0-3. |
| **Preload** | Carregamento antecipado dos dados do banco antes do inicio do jogo para processar herancas. |
