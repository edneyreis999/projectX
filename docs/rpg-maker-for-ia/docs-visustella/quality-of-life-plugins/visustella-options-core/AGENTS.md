# VisuStella Options Core

Documentacao catalogada do plugin Options Core (VisuMZ_1_OptionsCore) para RPG Maker MZ.

## Proposito

Reformular o menu de opcoes do RPG Maker MZ com categorias customizaveis, integracao com plugins VisuStella e opcoes de playtest.

## Principais Areas

- **conceitos/** - Visao geral, sistema de categorias, rebind de teclado/gamepad
- **configuration/** - Plugin Parameters: opcoes gerais, categorias, master volume shortcut
- **reference/** - Referencia completa de todas as opcoes por categoria + troubleshooting + glossario

## Arquivos Importantes

- [conceitos/visao-geral.md](conceitos/visao-geral.md) - Ponto de partida com dependencias opcionais
- [configuration/parametros-categorias.md](configuration/parametros-categorias.md) - Como criar opcoes customizadas via JS
- [conceitos/rebind-teclado-gamepad.md](conceitos/rebind-teclado-gamepad.md) - Limitacoes e WASD retroativo

## Ordem de Navegacao

1. conceitos/visao-geral.md
2. conceitos/categorias-opcoes.md
3. reference/opcoes-general.md (ou outra categoria conforme necessidade)
4. configuration/parametros-categorias.md (para customizacao)
5. reference/troubleshooting.md (para problemas)
