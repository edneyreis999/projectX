# Glossario - Options Core

| Termo | Definicao |
|-------|-----------|
| **Options Menu Scene** | Scene do RPG Maker MZ que exibe o menu de opcoes ao jogador |
| **Category Window** | Janela lateral que exibe as categorias de opcoes (General, Audio, UI, Playtest) |
| **Listed Option** | Opcao individual dentro de uma categoria, configuravel via JS |
| **Symbol** | Identificador unico de uma opcao, usado internamente pelo engine |
| **JS: Show/Hide** | Codigo JavaScript que determina se uma categoria ou opcao e visivel |
| **JS: Enable** | Codigo JavaScript que determina se uma opcao pode ser alterada |
| **JS: Default Value** | Codigo JavaScript que define o valor padrao de uma opcao (ON/OFF) |
| **JS: Ext** | Codigo JavaScript que define o valor ext (extension) de uma opcao |
| **Rebinding** | Recurso que permite ao jogador remapear teclas do teclado e botoes do gamepad |
| **config.rmmzsave** | Arquivo na pasta `/save/` que armazena configuracoes do jogador (incluindo keybindings) |
| **Master Volume** | Volume proporcional que afeta todos os outros tipos de volume (BGM, BGS, ME, SE) |
| **Touch UI** | Elementos de interface exclusivos para interacao por toque/clique |
| **Button Assist Window** | Janela que mostra texto de ajuda para botoes de acao (requer CoreEngine) |
| **Tier** | Sistema de prioridade de plugins VisuStella. Tier 1 = abaixo de Tier 0, acima de Tier 2+ |
| **Playtest Mode** | Modo de teste do RPG Maker MZ, acessado via editor. Opcoes de Playtest so aparecem neste modo |
| **Text Codes** | Codigos de formatacao de texto do RPG Maker MZ (ex: `\c[1]`, `\v[1]`) |
| **Action Sequence** | Sequencia de acoes visuais em batalha controlada pelo VisuStella Battle Core |
| **ATB** | Active Time Battle - Sistema de batalha com gauges de tempo |
| **Aggro** | Sistema de ameaca que determina qual membro do party inimigos atacam |
| **Negative State** | State com notetag `<Negative State>`, resistido pela opcao de Playtest |
