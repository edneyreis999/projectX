# Parametros Gerais - Options Settings

Parametros que afetam a aparencia e o comportamento do Options Menu Scene.

## Categories (Janela de Categorias)

| Parametro | Valores | Descricao |
|-----------|---------|-----------|
| Category Window Style | Text Only / Icon Only / Icon + Text / Auto | Como desenhar comandos na Category Window |
| Category Text Align | Left / Center / Right | Alinhamento de texto da Command Window |
| Background Type | - | Tipo de fundo da janela |

## Options Window

| Parametro | Descricao |
|-----------|-----------|
| Background Type | Tipo de fundo da janela de opcoes |

## Button Assist Window

| Parametro | Descricao |
|-----------|-----------|
| Switch Category | Texto do botao assist para trocar categorias (requer CoreEngine) |
| Background Type | Tipo de fundo (requer CoreEngine) |

## Sound

| Parametro | Descricao |
|-----------|-----------|
| Cursor Sounds | Lista de arquivos SE para som de cursor |
| OK Sounds | Lista de arquivos SE para som de confirmacao |
| Cancel Sounds | Lista de arquivos SE para som de cancelamento |
| Buzzer Sounds | Lista de arquivos SE para som de erro |

> O primeiro item de cada lista e sempre o SE padrao.

## Text

| Parametro | Descricao |
|-----------|-----------|
| Font Options | Lista de fontes disponiveis para o jogador selecionar |

> A primeira fonte da lista e sempre a fonte padrao.
