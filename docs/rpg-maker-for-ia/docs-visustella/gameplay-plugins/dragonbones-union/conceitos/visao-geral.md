# Visão Geral - DragonBones Union

## O que é DragonBones?

DragonBones permite que seus jogos usem animação esquelética (skeletal animation), um tipo de animação de computador em que um personagem (ou objeto) é representado por skins/texturas e um conjunto digital de ossos interconectados (chamado de esqueleto). Usando um conjunto de instruções, o jogo criará animações baseadas nessas skins, esqueletos e instruções para criar movimentos suaves e leves visualmente bonitos.

## Versão

A versão do Dragonbones usada neste plugin é **5.7.002b**.

Mais informações podem ser encontradas em: http://dragonbones.com/

## Funcionalidades

Este plugin adiciona suporte completo ao DragonBones no RPG Maker MZ, incluindo:

- **Adiciona suporte Dragonbones ao RPG Maker MZ**
- **Armatures Dragonbones podem ser usadas como sprites de battler**
- **Armatures Dragonbones podem ser anexadas a pictures de eventos**
- **Armatures Dragonbones podem ser inseridas no mapa como sprites de personagens**
- **Variety of Plugin Parameters, Notetags, and Plugin Commands** para controlar as armatures Dragonbones e suas animações

## Requisitos

### Plugin Obrigatório

- **Dragonbones*** - Biblioteca necessária

*Nota*: Você pode baixar esta biblioteca a partir da URL abaixo ou da página do produto Dragonbones Union. Instale como um plugin Tier 0.

URL: https://www.npmjs.com/package/pixi5-dragonbones/v/5.7.0-2b

### Compatibilidade

Este plugin é feito para **RPG Maker MZ**. Não funcionará em outras versões do RPG Maker.

### Tier

Este é um plugin **Tier 2**. Coloque-o abaixo de outros plugins com valor de tier menor na lista do Plugin Manager (ou seja: 0, 1, 2, 3, 4, 5). Isso garante melhor compatibilidade com o resto da biblioteca VisuStella MZ.

## Áreas de Aplicação

O plugin oferece controle sobre várias facetas do jogo:

1. **Sistema de Batalha** - Armatures como sprites de battlers
2. **Pictures de Eventos** - Armatures anexadas a pictures
3. **Sprites do Mapa** - Armatures como sprites de personagens no mapa
