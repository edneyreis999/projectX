# DragonBones - Armature Naming

## Problema: Encontrar o Nome Correto

Se você está tentando configurar uma armature Dragonbones através de notetags, Plugin Commands, etc., e está recebendo a mensagem de erro **"Cannot Read property 'parent' of null"**, muito provavelmente o nome incorreto da armature Dragonbones está sendo usado.

## Como Encontrar o Nome Próprio

Siga estes passos:

### Passo 1
Abra a armature Dragonbones no editor Dragonbones.

### Passo 2
Abra as Propriedades da armature (Properties).

### Passo 3
Olhe o que o campo "Name:" lista. **Este é o nome para usar com o plugin Dragonbones Union.**

## Importante

O nome que deve ser usado é exatamente o que aparece no campo "Name:" das propriedades da armature no editor Dragonbones, não o nome do arquivo.
