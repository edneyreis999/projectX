# Plugin Parameters - Experimental Settings

## Visão Geral

Estas configurações são experimentais e não foram testadas extensivamente ainda. Use com cautela.

---

## Experimental Settings

### Enemy Stances

**Descrição**: Enemies podem usar motions de stance para idling como chanting, guarding, etc.

**Detalhes**:
- **Requer**: VisuMZ_1_BattleCore!
- Não está disponível normalmente já que animações não estão disponíveis para enemies com os scripts core do RPG Maker MZ base
- **Desabilite** para usar o fluxo de animação padrão para enemies

**Quando Usar**:
- Quando você quer enemies com poses especiais (guarda, cantando, etc.)
- Quando está usando VisuStella Battle Core
- Quando quer animações mais dinâmicas para enemies

**Cuidado**: Recurso experimental. Pode ter comportamentos inesperados.
