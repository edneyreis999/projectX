# Events & Movement Core (VisuStella MZ)

## Proposito
Documentacao catalogada do plugin VisuStella Events & Movement Core para RPG Maker MZ. Tier 1 plugin que expande eventos, movimento, switches/variables e sprites.

## Principais Areas

### Conceitos (`conceitos/`)
- **visao-geral.md** - Funcionalidades, plugins de extensao, requisitos
- **switches-variables.md** - JS, Self, Map, Reference switches/variables
- **sprites-vs8.md** - Filename tags, VS8 format, emotes, weighted random

### Notetags (`notetags/`)
- **mapas.md** - Notetags para mapas (diagonal, regions, JS, visibility)
- **eventos.md** - Notetags para eventos (activation, movement, visual, hitbox, pictures, templates)
- **paginas.md** - Custom page conditions via comment tags

### Comandos (`comandos/`)
- **auto-movement.md** - Controlar movimento automatico
- **call-event.md** - Executar pagina de evento remoto
- **dash.md** - Toggle de dash
- **event-icon.md** - Icones sobre eventos/jogador
- **event-label.md** - Labels sobre eventos
- **event-location.md** - Localizacao, spawn, morph de eventos
- **event-popup.md** - Popups animados (requer MessageCore)
- **event-timer.md** - Timer, followers, global/self data

### Parametros (`parametros/`)
- **configuracao-geral.md** - Event templates e JavaScript hooks
- **labels-icones.md** - Configuracao de labels e icones
- **movement.md** - 8-dir, dash, shadows, pathfinding, turn in place
- **regioes-terrain.md** - Regions, common events por regiao, terrain tags

### Referencia (`referencia/`)
- **glossario.md** - Termos do plugin
- **script-calls.md** - Script calls e Move Route Custom Commands completos
- **troubleshooting.md** - Solucao de problemas comuns

1. `conceitos/visao-geral.md` → 2. `conceitos/switches-variables.md` → 3. `conceitos/sprites-vs8.md` → 4. `notetags/` → 5. `comandos/` → 6. `parametros/` → 7. `referencia/`
