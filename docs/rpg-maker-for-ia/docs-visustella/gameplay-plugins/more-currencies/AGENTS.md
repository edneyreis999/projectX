# More Currencies — VisuStella MZ

Plugin que expande o sistema de shop do RPG Maker MZ com suporte a múltiplas moedas (items, weapons, armors, variáveis, gold).

## Propósito

Permite que shops aceitem items, weapons, armors, variáveis ou gold como moeda — isoladamente ou em combinação. Suporta sistema de Proxy para vender o mesmo item com diferentes moedas em shops diferentes.

## Principais Áreas

- **Conceitos**: Visão geral e sistema de Proxy → `conceitos/`
- **Notetags**: Cost e Proxy notetags + referência rápida → `notetags/`
- **Configuração**: Parâmetros gerais e listing settings → `configuracao/`
- **Referência**: Vocabulário e requisitos → `referencia/`
