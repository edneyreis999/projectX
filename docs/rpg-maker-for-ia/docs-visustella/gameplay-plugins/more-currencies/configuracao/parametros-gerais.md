# Parâmetros Gerais

Configurações do plugin More Currencies acessíveis via Plugin Manager.

## General Settings

### General

| Parâmetro | Descrição |
|-----------|-----------|
| **Automatic Sell Rate** | Taxa de venda automática usada quando a notetag de custo não especifica Buy/Sell (variante "Cost" sem prefixo). Define qual fração do custo original é retornada ao vender. |

### Vocabulary

Textos exibidos na janela de transação (`Window_ShopNumber`):

| Parâmetro | Descrição |
|-----------|-----------|
| **Owned** | Texto para "quanto o jogador possui" de um recurso |
| **Shift** | Texto para "mudança de valor" (quanto será gasto/ganho) |
| **Net** | Texto para "resultado líquido" após a transação |

Esses textos aparecem na janela reformulada de compra/venda para indicar cada componente da transação.
