# Plugin Commands - Global

Comandos de plugin que afetam todos os atores do party simultaneamente.

## Global: Learn Equippable Passive

Todos os atores aprendem o(s) passivo(s) especificado(s).

**Parâmetros**:
| Parâmetro | Descrição |
|-----------|-----------|
| Passive State ID(s) | ID(s) dos states passivos |
| Show Text Popup? | Mostra popup para cada actor? |

## Global: Forget Equippable Passive

Todos os atores esquecem o(s) passivo(s) especificado(s).

**Parâmetros**:
| Parâmetro | Descrição |
|-----------|-----------|
| Passive State ID(s) | ID(s) dos states passivos a esquecer |

## Global: Add Unlearned Equippable Passive

Todos os atores recebem o(s) passivo(s) como learnable.

**Parâmetros**:
| Parâmetro | Descrição |
|-----------|-----------|
| Passive State ID(s) | ID(s) dos states a adicionar como unlearned |

## Global: Remove Unlearned Equippable Passive

Todos os atores têm o(s) passivo(s) removido(s) da lista learnable.

**Parâmetros**:
| Parâmetro | Descrição |
|-----------|-----------|
| Passive State ID(s) | ID(s) dos states a remover da lista unlearned |
